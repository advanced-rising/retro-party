# 레트로넷 (가칭) — 추억으로 노는 데일리 미니게임

> 모뎀 접속음이 나고, 메뉴가 뜨고, 번호를 누르면 게임이 시작된다.
> 첫 번째 게임은 **「그 해」** — 힌트를 하나씩 열어 연도를 맞히는 게임.

```
   ATDT 01410 ...
   CONNECT 14400

  ╔═══════════════════════════════════════════╗
  ║   한 별 정 보 통 신                        ║
  ║   ─────────────────────────────────────   ║
  ║                                           ║
  ║    1. 그 해                        NEW!   ║
  ║    2. 맞춤법 지옥                 준비중  ║
  ║    3. 전국구                      준비중  ║
  ║                                           ║
  ║    8. 오늘의 순위                         ║
  ║    9. 내 정보                             ║
  ║                                           ║
  ║   번호를 입력하세요 > _                    ║
  ╚═══════════════════════════════════════════╝
```

## 뭘 만드나

**하루 한 판, 1~3분짜리 미니게임을 모아놓은 레트로 플랫폼.**
90년대 PC통신에 접속한 것 같은 껍데기 하나에, 게임을 계속 얹어간다.

첫 타이틀 「그 해」는 이렇게 생겼다.

```
  그 해  #128                                시도 2 / 6
  ───────────────────────────────────────────────────
   힌트 1   자장면 한 그릇 2,500원
   > 1997                          ↓ 더 과거입니다  ❄

   힌트 2   이 해 데뷔한 그룹 — H.O.T
   > 1994                          ↑ 더 미래입니다  🔥

   힌트 3   ??????????
  ───────────────────────────────────────────────────
   > _
```

맞히면 그 해가 어떤 해였는지 한 장으로 펼쳐진다. 그게 진짜 재미다.

## 왜 되는가

| 조건 | 이 프로젝트 |
|---|---|
| 설명이 필요 없다 | "연도 맞히기"는 한 줄이면 끝 |
| 자기 실력을 확인하고 싶어진다 | 몇 번째 힌트에 맞혔나 = 자존심 |
| 데이터가 공짜고 깨끗하다 | 물가·환율·인구는 공공데이터. 나머지는 사실 정보 |
| 스크린샷 한 장이 훅 | PC통신 화면 + "이게 이 가격이었다고?" |
| 하루 한 번 돌아올 이유 | 데일리 1회 + 연속 출석 스트릭 |
| 확장이 쉽다 | 게임 모듈 플러그인 구조. 새 게임 = 파일 몇 개 |
