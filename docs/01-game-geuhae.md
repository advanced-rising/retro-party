# 01. 「그 해」 게임 디자인

> 힌트를 하나씩 열어 연도를 맞힌다. 하루 한 판.
> **맞히는 것보다 맞힌 다음에 펼쳐지는 화면이 진짜 목적이다.**

## 1. 핵심 루프

```
접속 ─→ 힌트 1 공개 ─→ 추측 ─→ 틀림, 힌트 2 공개 ─→ 추측 ─→ …
                                                          │
                          6번 안에 맞히거나 소진 ──────────┘
                                    ↓
                        ★ 「그 해」 요약 카드
                                    ↓
                          점수 · 스트릭 · 공유
```

### 1.1 플레이 화면

```
╔═══════════════════════════════════════════════════════╗
║  그 해  #128                              시도 2 / 6   ║
╠═══════════════════════════════════════════════════════╣
║                                                       ║
║   힌트 1   자장면 한 그릇 2,500원                      ║
║   > 1997                        ↓ 더 과거입니다   ❄   ║
║                                                       ║
║   힌트 2   이 해 데뷔한 그룹 — H.O.T                   ║
║   > 1994                        ↑ 더 미래입니다   🔥  ║
║                                                       ║
║   힌트 3   ??????????????????                         ║
║                                                       ║
╠═══════════════════════════════════════════════════════╣
║   연도를 입력하세요 > _              연속 출석 12일 🔥 ║
╚═══════════════════════════════════════════════════════╝
```

- 시작할 때 힌트 1개가 이미 열려 있다. **빈 화면에서 찍게 하지 않는다**
- 틀릴 때마다 힌트가 하나씩 추가된다
- 이전 추측과 피드백은 화면에 계속 남는다 (Wordle과 동일)

### 1.2 피드백 — 방향 + 온도

```
    ↑ 더 미래입니다 / ↓ 더 과거입니다
    ────────────────────────────────
    ±1년      🔥🔥   바로 옆입니다
    ±2~3년    🔥     가깝습니다
    ±4~7년    ·      멀지도 가깝지도
    ±8~15년   ❄      멉니다
    16년~     ❄❄     한참 멉니다
```

방향만 주면 이분탐색 기계가 되고, 온도까지 주면 **감으로 좁히는 재미**가 생긴다.

## 2. 힌트 설계 — 이 게임의 전부

### 2.1 카테고리

재미있는 순서다. 위쪽이 많이 나온다.

| # | 카테고리 | 예시 |
|---|---|---|
| 1 | **물가·생활비** | `자장면 한 그릇 2,500원` `지하철 기본요금 400원` |
| 2 | **대중문화** | `영화 「접속」 개봉` `이 해 데뷔 — H.O.T` |
| 3 | **기기·기술** | `삐삐 가입자 1,500만 명 돌파` `시티폰 서비스 시작` |
| 4 | 사건·뉴스 | `정부, IMF에 구제금융 요청` |
| 5 | 스포츠 | `프로야구 우승 — 해태 타이거즈` |
| 6 | 유행어 | `이 무렵 유행하던 말 — "야타족"` |
| 7 | 상품 출시 | `이 해 출시 — 포카칩` |
| 8 | 방송 | `이 해 최고 시청률 드라마 — 「모래시계」` |
| 9 | 통계 | `출생아 수 66만 명` `환율 1,695원` |
| 10 | 광고 | `이 해 광고 카피 — "말하지 않아도 알아요"` |

**1~3번이 전체의 60%를 차지한다.** 물가는 충격을 주고, 문화는 향수를 주고, 기기는 세대를 특정한다.

### 2.2 난이도 티어

힌트마다 티어 1~5. **어려운 것(T5)부터 나오고 뒤로 갈수록 쉬워진다.** 그래야 일찍 맞히는 게 실력이 된다.

| 티어 | 성격 | 예시 |
|---|---|---|
| **T5** 아주 어려움 | 여러 해에 걸쳐 성립. 방향만 잡아줌 | `출생아 수 66만 명` |
| **T4** 어려움 | 대략 5년 범위로 좁혀짐 | `삐삐 가입자 1,500만 명` |
| **T3** 보통 | 2~3년 범위 | `자장면 한 그릇 2,500원` |
| **T2** 쉬움 | 아는 사람은 바로 특정 | `영화 「접속」 개봉` |
| **T1** 거의 정답 | 그 해에만 있었던 일 | `IMF 구제금융 요청` |

한 판의 힌트 구성:
```
힌트 1 → T5     힌트 2 → T4     힌트 3 → T4
힌트 4 → T3     힌트 5 → T2     힌트 6 → T1
```

6번째 힌트는 거의 정답이다. **끝까지 가면 누구나 맞힐 수 있게** 만든다. 못 맞히고 끝나는 경험은 재방문을 죽인다.

### 2.3 힌트 문장 규칙

| 규칙 | 이유 |
|---|---|
| 25자 이내 | 한눈에 읽혀야 한다 |
| 연도를 직접 쓰지 않는다 | `1997년 개봉한 영화` ❌ → `이 해 개봉한 영화` ✅ |
| 단정하지 않을 건 부드럽게 | 유행어·인기상품은 `이 무렵` `~하던` 톤 |
| 숫자는 정확히 | 물가·통계는 출처가 있는 것만 |
| 재미 > 정보 | 지루한 사실보다 놀라운 사실 |

### 2.4 좋은 힌트의 조건

지루한 힌트를 걸러내는 게 콘텐츠 작업의 절반이다.

```
❌  이 해 GDP 성장률 5.8%          → 아무도 모르고 아무 감흥 없음
❌  이 해 대통령은 김영삼           → T1인데 너무 자주 쓰면 뻔해짐
✅  자장면 한 그릇 2,500원          → 즉시 체감. "이게 이 가격?"
✅  삐삐 가입자 1,500만 명          → 세대가 특정됨. 향수
✅  이 해 출시 — 프링글스 국내 판매  → 의외성
✅  버스 안내양이 사라진 해          → 시대의 단면
```

**판정 기준: 이 힌트를 보고 "아 맞다!" 소리가 나오는가.** 안 나오면 T5로 강등하거나 버린다.

## 3. 점수

```
맞힌 시도    1번    2번    3번    4번    5번    6번    실패
점수       1,000   800    620    460    320    200     0

+ 스트릭 보너스   연속 출석일 × 10  (상한 200)
```

속도 보너스는 **없다.** 급하게 찍는 걸 유도하면 힌트를 안 읽고, 힌트를 안 읽으면 이 게임의 재미가 통째로 사라진다. 빠른 게 좋은 사람은 스피드런 모드로 간다.

### 등급

```
1번  🏆 신급        (전체의 ~3%)
2번  ⭐ 고수        (~12%)
3번  👍 좋아요      (~28%)
4~5번 🙂 무난       (~40%)
6번  😅 아슬아슬    (~12%)
실패 😢 내일 또     (~5%)
```

## 4. ★ 「그 해」 요약 카드

**이 화면을 보려고 게임을 한다.** 맞혔든 틀렸든 항상 보여준다. 콘텐츠를 아끼지 않는다.

```
╔═══════════════════════════════════════════════════════╗
║                    1 9 9 7                            ║
╠═══════════════════════════════════════════════════════╣
║   자장면    2,500원      지하철 기본    400원          ║
║   최저임금  1,485원      환율      1,695원 ▲          ║
║   라면        400원      담배      1,000원            ║
╠═══════════════════════════════════════════════════════╣
║   이 해에 있었던 일                                    ║
║    · 정부, IMF에 구제금융 요청                         ║
║    · 영화 「접속」 개봉 — 관객 67만                     ║
║    · H.O.T 「늑대와 양」                               ║
║    · 프로야구 우승 — 해태 타이거즈                     ║
║    · 삐삐 가입자 정점 후 감소 시작                     ║
╠═══════════════════════════════════════════════════════╣
║   1번에 맞힌 사람        전체의  8%                    ║
║   가장 많이 찍은 오답    1998  (24%)                   ║
║   40대 평균 시도  2.3    20대 평균 시도  4.1           ║
╚═══════════════════════════════════════════════════════╝
        [S] 공유    [D] 다른 해 보기    [메뉴로]
```

### 4.1 세대차를 콘텐츠로

`40대 평균 2.3번 / 20대 평균 4.1번` — 이 한 줄이 공유를 부른다.

- "나 20대인데 2번에 맞혔음"
- "40대인데 5번 걸림 ㅋㅋ"

**자기 세대와 비교되는 순간 사람은 말하고 싶어진다.** 회원 가입 시 연령대를 선택 항목으로 받되, 안 받아도 게임은 돌아가게 한다.

### 4.2 「다른 해 보기」

요약 카드에서 좌우로 다른 연도를 넘겨볼 수 있다. **게임이 끝난 뒤에도 머무는 이유**를 만든다. 1980~2025 전 연도 아카이브가 사실상 하나의 콘텐츠가 된다.

**데일리가 본체다.** 나머지는 데일리를 기다리는 사이에 하는 것들이다.

## 7. 콘텐츠 고갈 문제 (정면으로)

연도는 유한하다. 1980~2025면 46개. 데일리로 매일 하나씩 쓰면 **46일이면 한 바퀴 돈다.** 이건 실제 문제다.

### 대응

| 방법 | 효과 |
|---|---|
| **연도 범위 확대** 1960~2025 → 66개 | 두 달 반 주기 |
| **힌트 풀 대량 확보** 연도당 60개+ | 6개씩 쓰면 한 연도로 10세트. 같은 해라도 완전히 다른 문제 |
| **힌트 재사용 금지 기간** 같은 유저에게 90일 내 중복 금지 | 개인별 체감 신선도 유지 |
| **테마 데이** (2년차~) 월=물가 / 수=문화 / 금=사건 | 같은 해도 결이 달라짐 |
| **정답을 기억해도 괜찮게** | "아 이 해 알아" → 1번에 맞힘 → 그것도 기분 좋음. 그 해를 배웠다는 뜻 |
| **시대 팩·주간 챌린지로 소비 분산** | 데일리 압력 완화 |

**현실적 계산**: 66연도 × 힌트 60개 = 약 4,000개 힌트가 필요하다. 힌트 세트 조합까지 고려하면 **2~3년치 데일리**가 나온다. 그 사이에 두 번째 게임을 만든다 (08 문서).

콘텐츠 확보는 02 문서의 파이프라인이 담당한다.

## 8. 밸런싱 자동화

힌트 티어를 사람이 감으로 매기면 반드시 틀린다. **플레이 데이터로 자가 보정한다.**

```
매일 배치:
  각 힌트별로 측정
    · 이 힌트가 공개된 직후 정답률
    · 이 힌트가 공개된 직후 추측의 평균 오차(년)
    · 이 힌트를 본 유저가 그 판을 끝낸 평균 시도 수

  → 실제 티어 재산정
     정답률 60%↑ = T1     40~60% = T2
     20~40% = T3          8~20% = T4     8%↓ = T5

  → 초기 수동 티어와 크게 다르면 플래그, 검토
```

이러면 **힌트가 많아질수록 밸런싱이 정확해진다.** 초기 티어는 대충 매겨도 된다는 뜻이기도 하다.

### 목표 분포

| 시도 | 목표 비율 |
|---|---|
| 1~2번에 맞힘 | 15% |
| 3~4번에 맞힘 | 50% |
| 5~6번에 맞힘 | 30% |
| 실패 | 5% |

**실패율 5%가 중요하다.** 0%면 너무 쉽고, 15%를 넘으면 재방문이 꺾인다.

## 9. 온보딩 (첫 판)

로그인 없이 바로 시작.

```
[0:00] 접속 연출 2초 (스킵 가능)
[0:02] 메뉴 → 1번 「그 해」
[0:05] 규칙 3줄. 텍스트만. 팝업 아님
       "연도 하나를 맞히세요"
       "틀릴 때마다 힌트가 하나씩 열립니다"
       "6번 안에 맞히면 성공"
[0:10] 첫 힌트 공개. 게임 시작
[~2:00] 정답 → 「그 해」 카드 → 공유 / 로그인 유도
```

**튜토리얼을 만들지 않는다.** 규칙이 세 줄이면 튜토리얼이 필요 없다.
로그인은 첫 판이 끝난 뒤에만 권한다. 게스트 기록은 저장해뒀다가 로그인 시 붙인다.

## 10. 열려 있는 결정 사항

| # | 항목 | 선택지 |
|---|---|---|
| G1 | 연도 범위 | 1980~ vs 1970~ vs 1960~ |
| G2 | 시도 횟수 | 6 vs 5 vs 7 |
| G3 | 온도 피드백 | 있음 vs 방향만 (있는 쪽이 쉬워짐) |
| G4 | 실패 시 정답 공개 | 즉시 공개 vs 다음날 공개 |
| G5 | 연령대 수집 | 필수 vs 선택 vs 안 받음 (세대 비교 콘텐츠와 직결) |
| G6 | 데일리 재도전 | 금지 vs 랭킹 비집계 재도전 |
