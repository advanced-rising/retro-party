# 00. 제품 개요

## 1. 한 문장

**방에 들어가면 사람들이 있고, 90년대 소재로 퀴즈를 풀며 채팅으로 떠드는 실시간 캐주얼 게임.**

큐플레이 · 캐치마인드 · 쿵쿵따의 구조를 그대로 가져오되, 소재는 90~2000년대 한국이고 UI는 2026년이다.

## 2. 왜 이 장르인가

### 2.1 그 게임들이 재밌었던 이유

큐플레이가 재밌었던 건 퀴즈가 어려워서가 아니다. **모르는 사람들과 같은 방에서 동시에 떠들었기 때문**이다.

| 요소 | 왜 중요한가 |
|---|---|
| **채팅이 곧 입력** | 답을 외치는 행위 자체가 소통이다. 별도 UI가 없다 |
| **동시성** | 남이 먼저 맞히는 걸 실시간으로 본다. 조급함이 재미 |
| **방에 머문다** | 한 판 끝나고 또 하고. 세션이 길어지는 유일한 구조 |
| **여러 명** | 4명 이상이어야 왁자지껄해진다. 1:1은 다른 게임 |
| **실력 편차 허용** | 못하는 사람도 채팅으로는 참여한다 |

### 2.2 지금 이걸 다시 만드는 이유

- **웹 기술이 따라왔다.** WebSocket + 엣지 인프라로 전용 게임서버 없이 만들 수 있다
- **모바일에서 할 수 있다.** 당시엔 PC방에 가야 했다
- **소재가 비어 있다.** 90년대 향수 콘텐츠는 소비되는데, 그걸 **같이 하는** 형태는 없다
- **AI로 콜드스타트를 넘길 수 있다.** 당시엔 불가능했던 카드 (03 문서)

## 3. 무게중심 — 실시간 방이 본체

| | 실시간 방 | 데일리 싱글 |
|---|---|---|
| 위치 | **본체** | 보조 |
| 목적 | 재미의 원천 | 유입 · 복귀 · 사람 없는 시간대 메우기 |
| 세션 | 10~30분 | 2분 |
| 개발 우선순위 | 1 | 2 |

**데일리 싱글을 없애지 않는 이유**: 새벽 3시에 들어온 사람이 빈 방 목록만 보고 나가면 그 사람은 안 돌아온다. 혼자서도 할 게 있어야 한다. 그리고 데일리를 끝낸 사람에게 *"지금 3번 방에 4명 있어요"*를 띄우는 게 가장 자연스러운 방 유입 경로다.

## 4. 코어 경험

```
[00:00] 접속 → 방 목록. "3번 방 5/8명 · 그 해" 가 보인다
[00:05] 입장 → 대기실. 아바타 5개, 채팅으로 인사
[00:20] 방장이 시작 → 라운드 1
[00:25]   힌트 하나 공개. 8초 뒤 또 하나
[00:38]   누가 "1997" 외침 → 정답. 다들 "아 ㅋㅋ"
[00:45]   정답 카드 3초 → 라운드 2
  ...
[10:00] 10라운드 종료 → 결과 → 대기실 복귀
[10:10] "한 판 더" → 반복
```

**한 번 들어오면 30분 있는다.** 이게 데일리 게임과 근본적으로 다른 지점이고, 이 제품이 노리는 것이다.

## 5. 타겟

### Primary — 30~40대
- 소재를 직접 겪었다. 힌트를 보면 몸이 반응한다
- 큐플레이·캐치마인드를 **실제로 했던** 세대. 형태만 봐도 안다
- 단톡방으로 방 코드를 뿌린다

### Secondary — 20대
- 겪지 않았지만 레트로를 소비한다
- 실시간 파티 게임(스크리블·가틱폰) 문법에 익숙하다
- **모르는 게 오히려 재밌다** — "이게 뭐야?" 하는 반응이 채팅을 만든다

### 유입 단위가 다르다
데일리 게임은 개인이 유입되지만, 이 장르는 **무리 단위로 유입된다.** 한 명이 방 코드를 던지면 5명이 들어온다. 그래서 초대 기능이 랜덤 매칭보다 먼저다.

## 6. 포지셔닝

```
              같이 함 ↑
                     │
   스크리블 · 가틱폰   │   ● 그때
   카훗                │
                     │
   ──────────────────┼──────────────────→ 향수 · 한국 소재
                     │
       퀴즈 앱        │   레트로 유튜브
       Wordle류       │   추억 커뮤니티
                     │
              혼자 함 ↓
```

- vs **스크리블 / 가틱폰**: 같은 실시간 방 구조. 우리는 **한국 90년대 소재**가 차별점
- vs **카훗**: 그쪽은 교육용 출제자-청중 구조. 우리는 동등한 참가자
- vs **레트로 유튜브 · 추억 커뮤니티**: 그쪽은 보는 것, 우리는 **같이 하는 것**
- vs **큐플레이**: 원본. 우리는 모바일 · 무설치 · 모던 UI

## 7. 브랜드

### 서비스명

UI를 모던하게 가져가므로 **이름도 PC통신 흉내를 내지 않는다.** 소재가 레트로일 뿐이다.

| 후보 | 장점 | 단점 |
|---|---|---|
| **그때** ⭐추천 | 짧다. 향수를 직접 지시. 로고로 만들기 좋음. 도메인 가능성 | 일반명사라 검색 불리 |
| 그때그때 | 리듬감, 검색 유리 | 조금 길다 |
| 타임머신 | 직관적 | 흔하다 |
| NOSTAL | 영문 짧음 | 한국 소재인데 영문이 어색 |
| 추억팔이 | 웃기고 각인됨 | 자조적 뉘앙스 |

**추천: 「그때」** / 태그라인 **"그때 우리 뭐 했더라"**

로고는 **도트 폰트로 「그때」 두 글자**. UI 전체는 모던하지만 로고에만 레트로를 남긴다 (06 문서).

> ⚠️ 상표·도메인 확인 필요 (08 문서). 일반명사라 상표 등록이 어려울 수 있음 — 로고 결합 상표로 접근.

## 8. 성공 지표

데일리 게임과 완전히 다른 지표를 본다.

### North Star
**"사람이 2명 이상 있는 방의 수"** — 빈 방은 없는 것과 같다.

| 지표 | MVP(2개월) | 6개월 | 12개월 |
|---|---|---|---|
| **피크 동시접속(CCU)** | 150 | 1,200 | 5,000 |
| **평균 방 인원** | 3.5 | 5.0 | 5.5 |
| **AI 참가자 비율** | 45% | 25% | 12% |
| 평균 세션 길이 | 12분 | 20분 | 25분 |
| 세션당 판 수 | 1.5 | 2.5 | 3 |
| D1 리텐션 | 25% | 35% | 40% |
| D7 리텐션 | 12% | 22% | 28% |
| 방 코드 초대 발생률 | 8% | 15% | 18% |
| 데일리 싱글 → 방 전환율 | 15% | 25% | 30% |

**AI 참가자 비율이 시간에 따라 내려가는 게 건강 신호다.** 안 내려가면 실제 유저가 안 늘고 있다는 뜻이다 (03 문서).

**MAU를 North Star로 쓰지 않는다.** 이 장르는 한 달에 한 번 오는 100만 명보다 매일 저녁 있는 1,000명이 낫다.

## 9. 하지 않을 것

| 안 함 | 이유 |
|---|---|
| AI 참가자를 사람인 척 위장 | 들키면 신뢰가 끝난다. 표시하되 캐릭터로 만든다 (03 문서) |
| 확률형 아이템 · 게임 재화 판매 | 캐주얼 파티 게임의 분위기를 망친다 |
| 채팅 로그 저장 | 휘발이 원칙 (08 문서) |
| 로그인 강제 | 방에 들어가는 데 가입이 필요하면 무리 유입이 죽는다 |
| 랜덤 매칭 자유 채팅 | 낯선 사람 리스크. 이모트만 (08 문서) |
| 24시간 균등 운영 | 사람을 분산시키면 아무데도 사람이 없다 (03 문서) |
