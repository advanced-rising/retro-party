# 07. 로드맵

> 원칙 둘.
> ① **재미 검증에 코드가 필요 없다** — 이 장르는 사람이 진행자 역할을 하면 바로 테스트된다.
> ② **콜드스타트가 개발보다 어렵다** — 게임을 다 만들어도 사람이 없으면 끝이다.

## Phase 0 — 코드 없이 재미 검증 (1주)

**아무것도 만들지 않는다.** 디스코드나 단톡방에서 사람이 직접 진행한다.

### 방법

```
지인 5~7명을 디스코드 텍스트 채널에 모은다
내가 진행자 역할로 문제를 낸다

① 초성 퀴즈   "ㅅㅍㄱ / 90년대 물건 / 허리에 차고 다녔다"
              → 채팅으로 맞히기, 20초
② 단어 연상   한 명에게 DM으로 단어를 주고 설명하게 한다
              → 채팅으로 맞히기, 90초
③ 그 해       힌트를 8초 간격으로 직접 타이핑
              → 채팅으로 연도 외치기

각 게임 5라운드씩, 총 3세션 (다른 사람들로)
```

### 무엇을 측정하나

| 질문 | 판단 기준 |
|---|---|
| **채팅이 살아나는가** | 라운드당 메시지 15개 이상 |
| **어느 게임이 제일 웃긴가** | 세션 후 물어봤을 때 다수가 꼽는 것 |
| **단어 연상이 진짜 되는가** | 정답률 50~80%, 설명이 재밌는가 |
| **라운드 길이가 적절한가** | 늘어지거나 급하지 않은가 |
| **한 판 더 하고 싶은가** | 3세션 중 2번 이상 "또 하자" |

### 관문 G0

- 3세션 중 **2번 이상 "또 하자"** 가 나온다
- 라운드당 채팅 15개 이상
- 세 게임 중 **최소 하나는 확실히 재밌다**

**여기서 안 되면 만들어도 안 된다.** 비용 0, 기간 1주로 가장 중요한 걸 검증한다.
결과에 따라 게임 우선순위가 바뀔 수 있다 — 단어 연상이 압도적이면 그것부터 만든다.

## Phase 0.5 — 실시간 뼈대 (2주)

**초성 퀴즈 하나만**으로 방 구조가 실제로 도는지 확인한다.

| 항목 | 내용 |
|---|---|
| 게임 | 초성 퀴즈만 (구현 최소) |
| 방 | 하드코딩 1개. 목록 · 생성 없음 |
| 인증 | 없음. 닉네임만 입력 |
| 콘텐츠 | 손으로 만든 문제 50개 |
| UI | 디자인 시스템 골격만 |
| AI | 없음 |

### 관문 G0.5

| 항목 | 기준 |
|---|---|
| 채팅 왕복 (p95) | < 150ms |
| 8명 동시 접속 | 끊김 없이 10라운드 완주 |
| 재접속 | 모바일에서 앱 나갔다 와도 복귀 |
| **키보드 가림** | 모바일에서 입력창이 안 가려진다 |

**마지막 항목이 은근히 중요하다.** 여기서 막히면 모바일 유저를 통째로 잃는다.

## Phase 1 — MVP (8주)

**질문: 저녁 9시에 방 두 개가 사람으로 차는가?**

### 범위

| 포함 | 제외 |
|---|---|
| 게임 3종 (초성 · 단어연상 · 그 해) | 4번째 게임 |
| **멀티 캐주얼방** — 목록 · 생성 · 코드 입장 | 랜덤 매칭 |
| **싱글 데일리 3종** + 연습 | — |
| **레벨 1~100 + 레벨 칭호** | 업적 칭호 · 히든 칭호 |
| **데일리 랭킹** (일간) | 랭크전 · 급/단 · 시즌 |
| **팀전 4:4** (+3v3·2v2 축소 편성, 팀 채팅 분리) | 팀 랭크 |
| **AI 참가자** (03 문서) | — |
| **프라임타임 운영** (하루 1시간) | 24시간 운영 |
| 게스트 플레이 | 계정 (선택 가입만) |
| 결과 공유 카드 | 전적 페이지 |
| 콘텐츠: 초성 800 · 연상 600 · 힌트 700 | 전량 |

**팀전 4:4를 MVP에 넣는다.** 8명 정원의 완성형이고, **실력 편차를 덮어줘서 초기 이탈을 줄인다.** 팀 채팅 분리만 제대로 만들면 나머지는 캐주얼방 로직 재사용이다.

다만 **8명 모으기는 4명보다 훨씬 어렵다.** 그래서 인원에 따라 3v3·2v2로 자동 축소하고, 모자라면 양 팀에 균등하게 AI를 넣는다 (01 문서 §6.5.1). 4:4는 **단톡방 초대 경로**를 주 타겟으로 본다.

**레벨과 데일리 랭킹을 MVP에 넣는다.** 둘 다 사람이 없어도 작동한다 — 콜드스타트 시기에 "뭔가 쌓인다"는 감각이 유일한 잔류 이유가 된다 (10 문서 §7).

### 주차별

| 주 | 콘텐츠 (Claude Code) | 코드 |
|---|---|---|
| W1 | 초성 800 · 연상 단어 600 | `room-kit` 인터페이스, RoomDO 확장 |
| W2 | 계속 + AI 채팅 문구 풀 | 단어 연상 구현 (금칙어 차단 포함) |
| W3 | 「그 해」 힌트 착수 (~250) | 방 목록 · 생성 · 코드 입장 |
| W4 | 계속 (~500) | AI 참가자 (행동 계획 · 페르소나) |
| W5 | 계속 (~700) + 검증 | 「그 해」 구현, 정산 카드 |
| W6 | 사람 검수 | **팀전 4:4 (팀 채팅 분리 · 자동 편성)** + 공유 카드 |
| W7 | 마무리 | **싱글 데일리 3종 + 레벨/칭호 + 데일리 랭킹**, 프라임타임 |
| W8 | — | 모바일 다듬기, 소프트 런칭 |

MVP가 7주 → **8주**로 늘었다. 팀전과 데일리 랭킹이 추가됐기 때문이다.

**단어 연상을 W2에 먼저 만든다.** 콘텐츠 부담이 없어서 가장 빨리 완성되고, Phase 0에서 가장 재밌을 가능성이 높다.

### 성공 판정 (런칭 후 3주)

| 지표 | 목표 |
|---|---|
| **프라임타임 피크 동접** | **60** |
| **신규 방문자가 사람 있는 방을 본 비율** | **50% 이상** ★ |
| 평균 방 인원 | 3.5 |
| AI 참가자 비율 | 50% 이하 |
| 평균 세션 길이 | 12분 |
| D1 리텐션 | 25% |
| 방 코드 초대 발생률 | 8% |

**★ 표시 지표가 이 Phase의 생사다** (03 문서 §9). 다른 게 다 좋아도 이게 50% 미만이면 확장하지 않고 콜드스타트만 다시 판다.

### 초기 유입 (돈 안 쓰는 것)

우선순위 순:

1. **지인 단톡방** — 첫 20명. 가장 현실적
2. **스트리머·유튜버에게 방 코드 제공** ★ — 시청자가 무리로 들어온다. **이 장르에 가장 잘 맞는 채널**
3. 90년대 향수 커뮤니티 · 카페 시딩
4. 결과 공유 카드 자연 확산
5. 레트로 소재 SNS 콘텐츠 → 데일리 → 방

**2번에 가장 공을 들인다.** 시청자 수백 명이 동시에 들어오면 그 순간 콜드스타트가 해결되고, 그날 잡은 사람들이 다음 날의 씨앗이 된다.

## Phase 2 — 밀도 높이기 (8주)

**질문: 프라임타임 밖에도 사람이 있는가?**

| 항목 | 내용 |

## 인력

| 역할 | Phase 0~1 | Phase 2~3 |
|---|---|---|
| 풀스택 개발 | 1 (겸 기획) | 2 |
| 콘텐츠 검수 | 0.3 (겸임) | 0.7 |
| 디자이너 | 0 (shadcn + 오픈소스 에셋) | 0.5 (외주) |
| **커뮤니티 운영** | **0.3** ★ | 1 |

**커뮤니티 운영이 Phase 1부터 필요하다.** 프라임타임에 직접 들어가서 방을 채우고 분위기를 만드는 사람이 있어야 한다. 초기엔 개발자 본인이 한다.

## 위험 관문

| 관문 | 조건 | 미통과 시 |
|---|---|---|
| **G0** | 3세션 중 2번 "또 하자", 라운드당 채팅 15+ | 게임 규칙 재설계. 여기서 막히면 전부 중단 |
| **G0.5** | 채팅 p95 < 150ms, 모바일 키보드 정상 | 실시간 구조 재검토 |
| **G1 ★** | **신규 방문자가 사람 있는 방을 본 비율 50%+** | 확장 중단, 콜드스타트만 다시 판다 |
| G1 | 프라임타임 동접 60, D1 25% | 유입 채널 재설계 (스트리머 집중) |
| G2 | AI 비율 30% 이하 | 실제 유저가 안 늘고 있다 — 확장 보류 |
| G3 | 피크 동접 400, D7 20% | 수익화 보류 |

**G1의 ★ 지표가 이 프로젝트 전체의 단일 최중요 지표다.** 대시보드 맨 위에 둔다.
