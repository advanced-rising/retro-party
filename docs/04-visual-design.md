# 05. 비주얼 디자인 — 가상 PC통신

> 목표: **스크린샷 한 장으로 설명이 끝나는 화면.**
> 제약: 향수가 가독성을 이기면 안 된다. 힌트 텍스트는 반드시 읽혀야 한다.

## 1. 레퍼런스

- 1990년대 PC통신 (하이텔·천리안·나우누리) 터미널 화면
- 이야기 / 새롬데이타맨 등 통신 에뮬레이터
- DOS 텍스트 UI, 도트 매트릭스 프린터 출력
- 브라운관 CRT의 인광·잔상·스캔라인

**의도적으로 피하는 것**: SF 터미널, 매트릭스 코드비, 사이버펑크 네온.
우리 감성은 **미래가 아니라 과거**다. 촌스럽고 실용적이어야 한다.

## 2. 컬러

```css
:root {
  /* 배경 */
  --bg-void:    #050705;   /* 화면 밖, 베젤 */
  --bg-screen:  #0A0F0A;   /* 메인 화면 */
  --bg-panel:   #0E140E;   /* 패널 */
  --bg-select:  #1A2A1A;   /* 선택 행 */

  /* 인광 텍스트 */
  --fg-primary: #33FF66;   /* 본문 인광 그린 */
  --fg-dim:     #1E9940;   /* 보조 */
  --fg-bright:  #B4FFC8;   /* 강조, 커서 */
  --fg-frame:   #2A7A45;   /* 박스 드로잉 */

  /* 피드백 */
  --hot:        #FF6B35;   /* 🔥 가깝다 */
  --cold:       #4FA8FF;   /* ❄ 멀다 */
  --correct:    #FFD700;   /* 정답 */
  --amber:      #FFB000;   /* 알림 */
}
```

### 사용 규칙

- 인광 그린은 **텍스트/프레임 전용**
- 주황/파랑은 **온도 피드백에만**. 다른 데 쓰면 신호가 죽는다
- 정답의 금색은 **한 판에 한 번**만 등장한다. 그래서 특별하다
- 색만으로 정보를 전달하지 않는다 — `🔥 가깝습니다` 처럼 텍스트 병기

## 3. 타이포그래피

| 용도 | 폰트 | 라이선스 |
|---|---|---|
| 한글 UI | **Galmuri11** | SIL OFL 1.1 ✅ |
| 한글 큰 제목 | **Galmuri14** | SIL OFL 1.1 ✅ |
| 영문/숫자 | **IBM Plex Mono** | SIL OFL 1.1 ✅ |

```css
.terminal {
  font-family: 'Galmuri11', 'IBM Plex Mono', monospace;
  font-size: 14px;
  line-height: 20px;
  font-variant-numeric: tabular-nums;   /* 연도·가격 정렬 필수 */
  text-shadow: 0 0 4px currentColor;    /* 인광 번짐 */
}
```

연도와 가격이 계속 나오는 게임이라 `tabular-nums`가 특히 중요하다.

## 4. 화면

### 4.1 접속 (첫 진입)

```
   ATDT 01410 ...
   CONNECT 14400
```

모뎀 접속음(기본 OFF) + 텍스트가 한 줄씩 찍히는 연출 2초. 아무 키로 스킵.
재방문 시 0.8초. **이 시간에 오늘의 퍼즐을 받아온다.**

### 4.2 메뉴

```
  ╔═══════════════════════════════════════════════╗
  ║   한 별 정 보 통 신              1996          ║
  ║   ─────────────────────────────────────────   ║
  ║   손님, 어서 오세요.                           ║
  ║   오늘 접속 12,481번째                         ║
  ║                                               ║
  ║    1. 그 해                          NEW!     ║
  ║    2. 맞춤법 지옥                   준비중    ║
  ║    3. 전국구                        준비중    ║
  ║                                               ║
  ║    8. 오늘의 순위                             ║
  ║    9. 내 정보           연속 출석 12일 🔥     ║
  ║                                               ║
  ║   번호를 입력하세요 > _                        ║
  ╚═══════════════════════════════════════════════╝
```

- 숫자 키 입력 **또는** 클릭/탭 둘 다 동작한다. 키보드는 감성, 클릭은 접근성
- 게임이 늘어도 줄 하나 추가면 끝 — 이 레이아웃의 목적
- 우측 상단 연도는 장식. 재미로 매일 바뀐다

### 4.3 「그 해」 플레이

```
  ╔═══════════════════════════════════════════════════════╗
  ║  그 해  #128                              시도 2 / 6   ║
  ╠═══════════════════════════════════════════════════════╣
  ║                                                       ║
  ║   힌트 1   자장면 한 그릇 2,500원                      ║
  ║   > 1997                        ↓ 더 과거입니다   ❄   ║
  ║                                                       ║
  ║   힌트 2   이 해 데뷔한 그룹 — H.O.T                   ║
  ║   > 1994                        ↑ 더 미래입니다   🔥  ║
  ║                                                       ║
  ║   힌트 3   ??????????????????                         ║
  ║                                                       ║
  ╠═══════════════════════════════════════════════════════╣
  ║   연도를 입력하세요 > _              연속 출석 12일 🔥 ║
  ╚═══════════════════════════════════════════════════════╝
```

원칙:
1. **이전 시도가 전부 화면에 남는다.** 추론 게임이라 되짚어봐야 한다
2. 미공개 힌트는 `?`로 자리를 차지한다 — 몇 개 남았는지 보인다
3. 입력창은 항상 하단 고정. 커서가 깜빡인다

### 4.4 힌트 공개 연출

```
   힌트 3   ??????????????????
             ↓ 0.4초 타이핑
   힌트 3   이 해 개봉 — 「접속」
```

한 글자씩 찍히는 타자기 연출 0.4초. 짧지만 **"새 정보가 왔다"는 신호**로 충분하다.
스킵 가능.

### 4.5 정답 순간

```
   > 1997

              ██  █████   █████  ███
             ███  ██  ██ ██   ██   ██
              ██  ██  ██ ██   ██  ██
              ██   █████   █████  ██████

              정   답   입   니   다
```

금색 도트 숫자로 연도가 크게 찍힌다. 0.8초 유지 후 「그 해」 카드로 전환.
**이 게임에서 가장 기분 좋은 0.8초다.** 아끼지 않는다.

### 4.6 「그 해」 요약 카드

```
  ╔═══════════════════════════════════════════════════════╗
  ║                    1 9 9 7                            ║
  ╠═══════════════════════════════════════════════════════╣
  ║   자장면    2,500원      지하철 기본    400원          ║
  ║   최저임금  1,485원      환율      1,695원 ▲          ║
  ║   라면        400원      담배      1,000원            ║
  ╠═══════════════════════════════════════════════════════╣
  ║   이 해에 있었던 일                                    ║
  ║    · 정부, IMF에 구제금융 요청                         ║
  ║    · 영화 「접속」 개봉 — 관객 67만                     ║
  ║    · H.O.T 「늑대와 양」                               ║
  ║    · 프로야구 우승 — 해태 타이거즈                     ║
  ╠═══════════════════════════════════════════════════════╣
  ║   1번에 맞힌 사람        전체의  8%                    ║
  ║   가장 많이 찍은 오답    1998  (24%)                   ║
  ║   40대 평균 시도  2.3    20대 평균 시도  4.1           ║
  ╚═══════════════════════════════════════════════════════╝
     ◀ 1996        [S] 공유    [메뉴로]        1998 ▶
```

- 좌우로 다른 연도를 넘겨볼 수 있다 (01 문서 §4.2)
- 숫자는 도트 매트릭스 프린터로 찍히는 듯한 연출 (0.6초)
- **이 화면이 이 게임의 목적지다.** 여기에 가장 공을 들인다

## 5. 효과

| 효과 | 시간 | 스킵 |
|---|---|---|
| 접속 연출 | 2.0s (재방문 0.8s) | ✓ |
| 힌트 타이핑 | 0.4s | ✓ |
| 피드백 표시 | 0.3s | ✕ |
| 정답 연출 | 0.8s | ✓ |
| 「그 해」 카드 등장 | 0.6s | ✓ |

데일리 게임은 60초 게임보다 여유가 있지만, **연출 총합이 4초를 넘기지 않는다.**

### CRT 오버레이

```css
.crt::before {                    /* 스캔라인 */
  content: ''; position: fixed; inset: 0; pointer-events: none; z-index: 9000;
  background: repeating-linear-gradient(
    to bottom,
    rgba(0,0,0,0) 0px, rgba(0,0,0,0) 2px,
    rgba(0,0,0,.18) 3px, rgba(0,0,0,.18) 3px);
}
.crt::after {                     /* 비네팅 */
  content: ''; position: fixed; inset: 0; pointer-events: none; z-index: 9001;
  background: radial-gradient(ellipse at center,
    rgba(0,0,0,0) 55%, rgba(0,0,0,.42) 100%);
}
@media (prefers-reduced-motion: reduce) {
  .crt::before { display: none; }
  .flicker, .typewriter { animation: none; }
}
```

| 효과 | 강도 | 비고 |
|---|---|---|
| 스캔라인 | opacity .18 | 힌트 텍스트가 읽혀야 한다. 60초 게임보다 약하게 |
| 인광 글로우 | `text-shadow: 0 0 4px` | |
| 커서 블링크 | 530ms | 실제 CRT 터미널 주기 |
| 화면 깜빡임 | **기본 OFF** | 읽는 게임이라 방해된다 |

**전부 설정에서 끌 수 있다.**

### 사운드

| 이벤트 | 소리 |
|---|---|
| 접속 | 모뎀 핸드셰이크 |
| 키 입력 | 기계식 키보드 클릭 |
| 힌트 공개 | 텔레타이프 틱틱 |
| 틀림 | 짧은 부저 |
| 정답 | 상승 톤 시퀀스 |
| 「그 해」 카드 | 도트 프린터 인쇄음 |

**기본 OFF.** 모뎀 소리는 켜면 최고지만 자동재생은 이탈 요인이다.

## 8. 반응형

| 뷰포트 | 전략 |
|---|---|
| ≥1024px | 풀 레이아웃, 96칸 그리드 |
| 768~1023 | 80칸으로 축소 |
| <768 (모바일) | 40칸 재구성. 입력창 하단 고정, 숫자 키패드 자동 호출 |

모바일에서 연도 입력은 **숫자 키패드**(`inputmode="numeric"`)를 띄운다.
네 자리 입력이라 이것만으로 체감이 크게 달라진다.

터미널 느낌은 모바일에서도 유지한다. 앱스러운 카드 UI로 바꾸면 정체성이 사라진다.

## 9. 접근성

| 항목 | 처리 |
|---|---|
| CRT 효과 | `prefers-reduced-motion` 존중 + 토글 |
| 색상 | 온도 피드백에 색 + 이모지 + 텍스트 3중 표기 |
| 키보드 | 전 기능 키보드 조작 |
| 스크린리더 | 힌트와 피드백을 `aria-live="polite"`로 읽어줌 |
| 저시력 | 폰트 크기 3단계 (14/16/20px), 스캔라인 OFF 시 대비 강화 |
| 시간 압박 | **데일리 「그 해」에는 시간 제한이 없다** — 접근성 이점 |

「그 해」가 시간 제한 없는 게임이라는 게 접근성 측면에서 큰 강점이다. 향후 시간 제한 게임을 추가할 때는 별도 완화 모드가 필요하다.
