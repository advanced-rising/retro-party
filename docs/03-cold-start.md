# 03. 콜드스타트 전략

> **이 장르는 거의 항상 여기서 죽는다.**
> 게임이 재밌어도, UI가 예뻐도, 방에 사람이 없으면 아무 의미가 없다.
> 이 문서는 그것만 다룬다.

## 1. 문제

### 1.1 죽음의 나선

```
사람이 없다
   ↓
신규 방문자가 빈 방 목록을 본다
   ↓
"아무도 없네" → 즉시 이탈
   ↓
다시 오지 않는다
   ↓
사람이 더 없다
```

**한 번 이 나선에 들어가면 못 빠져나온다.** 광고로 사람을 밀어 넣어도 그들이 또 빈 방을 보면 똑같이 나간다. 유입에 쓴 돈이 그대로 증발한다.

### 1.2 데일리 게임과의 결정적 차이

| | Wordle 계열 | 실시간 방 |
|---|---|---|
| 유저 1명일 때 | **정상 작동** | 작동 안 함 |
| 유저 10명일 때 | 정상 작동 | 시간대가 어긋나면 여전히 0 |
| 필요 동접 | 0 | **최소 3~4명 (동시에)** |

핵심은 **MAU가 아니라 동시성**이다. 하루 1,000명이 각자 다른 시간에 오면 방은 계속 비어 있다.

### 1.3 우리 게임별 최소 인원

| 게임 | 최소 | 재밌어지는 선 | 정원 |
|---|---|---|---|
| 초성 퀴즈 | 2 | 4 | 8 |
| 그 해 | 2 | 4 | 8 |
| **단어 연상** | **3** | 5 | 8 |
| **팀전 4:4** | **8** ★ | 8 | 8 |

단어 연상이 게임 중 가장 취약하다 — 출제자 1명 + 맞히는 사람 2명이 최소인데, 초기에 가장 재밌는 게임이 가장 안 돌아간다.

**팀전 4:4는 8명이 필요해 콜드스타트에 가장 취약하다.** 그래서 4:4는 **초대 방 중심**으로 설계한다 — 단톡방 8명이 그대로 한 판이 되는 경로가 랜덤 매칭보다 훨씬 현실적이다 (§6). 인원이 모자라면 §3.5의 규칙대로 **양 팀에 균등하게** AI를 넣어 3v3·2v2로 축소하거나 4:4를 채운다.

## 2. 다섯 개의 축

| # | 전략 | 역할 |
|---|---|---|
| 1 | **AI 참가자** | 3명을 6명으로 만든다 |
| 2 | **프라임타임 집중** | 흩어진 사람을 한 시간대로 모은다 |
| 3 | **데일리 싱글** | 사람 없는 시간에 할 거리를 준다 |
| 4 | **초대 우선** | 무리 단위 유입을 만든다 |
| 5 | **뭉치기 압력** | 있는 사람이라도 한 방에 모은다 |

**AI는 0명을 5명으로 만드는 도구가 아니다.** 3명을 6명으로 만드는 도구다. 진짜 사람 2~3명은 반드시 있어야 하고, 그건 4·5번이 담당한다.

## 3. 축 1 — AI 참가자

### 3.1 대원칙: 숨기지 않는다

```
◇ 96학번        ← 닉네임 앞에 항상 표시
   프로필: AI 참가자
```

**숨기면 반드시 들킨다.** 그리고 들키는 순간 "여기 봇밖에 없대"라는 말이 커뮤니티에 돌고, 그걸로 끝이다.

반대로 대놓고 표시하면 유저는 이렇게 받아들인다: *"아 사람 부족해서 채워주는구나."* 불쾌하지 않다. 오히려 혼자 남는 것보다 낫다.

첫 조우 시 툴팁 1회:
```
◇ 는 AI 참가자예요.
사람이 부족할 때 자리를 채워주고, 사람이 오면 비켜줍니다.
```

### 3.2 캐릭터로 만든다

기계적인 `Bot1`, `Bot2`는 흥을 깬다. **페르소나를 준다.**

| 이름 | 성격 | 강점 |
|---|---|---|
| ◇ **96학번** | 느긋함. "그때가 좋았지" | 90년대 초중반 |
| ◇ **밀레니엄** | 발랄함 | 2000년대 |
| ◇ **만렙** | 빠르고 잘 맞힘 | 전 범위 (긴장감 담당) |
| ◇ **눈치백단** | 항상 2~3등 | 애매하게 잘함 |
| ◇ **오락실죽순이** | 게임·문화 소재에 강함 | 특화 |

**「그 해」에서 96학번이 90년대 문제를 잘 맞히는 것** 같은 일관성이 캐릭터를 만든다.

### 3.3 실력 조절 — 사람이 이기게 한다

| 항목 | 설정 |
|---|---|
| 정답률 | 55~70% (사람 평균과 비슷) |
| 반응 시간 | 정답 조건 충족 후 랜덤 3~15초 |
| **1등 빈도** | **전체 라운드의 20% 이하** |
| 오답 | 가끔 근접 오답을 낸다 (`1996?`) |
| 채팅 | 상황별 사전 문구 풀에서 선택 |

**AI가 1등을 독식하면 사람이 나간다.** 방에 사람이 많을수록 AI 실력을 낮춘다.

```
방에 사람 1명 → AI 실력 하향 (사람이 1등 하게)
방에 사람 4명 → AI 실력 중립 (구색만)
```

### 3.4 채팅 — 런타임 LLM 없이

AI도 채팅을 쳐야 방이 산다. 하지만 **런타임에 LLM을 호출하지 않는다.**

```
상황별 사전 문구 풀 (각 30개 이상)
  라운드 시작    "가보자", "이번엔 맞춰야지"
  정답 맞힘      "오ㅋㅋ", "이건 알지", "나 이거 씀"
  오답           "아닌가", "음...", "확실한데"
  남이 맞힘      "빠르네", "ㅋㅋㅋ", "아 알았는데"
  정산 반응      "아 맞다", "그때 그랬지"
  출제자일 때    (단어별 사전 생성 설명 스크립트)
```

- 문구는 **캐릭터별로 다르다** (96학번은 옛날 말투, 밀레니엄은 발랄)
- 같은 방에서 같은 문구 반복 금지
- 4 문서 파이프라인에서 같이 생성한다

**단어 연상 AI 출제자**: 단어당 3단계 설명 스크립트를 미리 만들어두고 시간에 따라 흘린다. 사람 출제자만큼 재밌진 않지만, 라운드가 돌아가게는 한다.

### 3.5 투입·퇴장 규칙

```
게임 시작 시 방 인원 < 4
  → 부족분만큼 AI 투입 (최대 3명)

팀전에서 인원이 짝수가 아니거나 모자람
  → 양 팀에 균등하게 AI 투입 (01 문서 §6.5.1)
     8명 → 4v4 / 7명 → 4v4(AI 1) / 6명 → 3v3 / 5명 → 3v3(AI 1)
  → 한쪽 팀만 AI면 불공평하다고 느낀다. 반드시 균등

라운드 진행 중 실제 사람이 입장
  → 라운드 종료 후 AI 1명 퇴장
     "자리 비켜드릴게요"

방에 사람이 0명이 됨
  → 방 즉시 해체 (AI만 남은 방은 존재 이유가 없다)
```

**AI만 있는 방은 만들지 않는다.** 사람이 최소 1명은 있어야 AI가 들어온다.

### 3.6 추적 지표

| 지표 | 의미 | 경보선 |
|---|---|---|
| AI 참가자 비율 | 전체 참가자 중 AI | **> 60% 지속** |
| AI 1등 비율 | AI가 1등한 라운드 | > 25% |
| AI 있는 방의 세션 길이 | 없는 방 대비 | 70% 미만이면 AI가 흥을 깨는 것 |

**AI 비율은 시간이 갈수록 내려가야 한다.** 안 내려가면 실제 유저가 안 늘고 있다는 뜻이고, 그건 AI로 가릴 수 없는 문제다.

## 4. 축 2 — 프라임타임 집중

### 4.1 24시간 균등 운영은 자살이다

동접 100명이 24시간에 퍼지면 시간당 4명이다. 방 하나도 못 채운다.
같은 100명이 2시간에 모이면 시간당 50명. **방 8개가 돈다.**

### 4.2 운영 시간

| Phase | 프라임타임 |
|---|---|
| **1 (동접 0~50)** | **평일·주말 21:00~22:00** — 하루 1시간만 |
| 2 (50~300) | 평일 21:00~23:00 / 주말 14:00~16:00 추가 |
| 3 (300+) | 상시 + 프라임타임 가중 |

**초기엔 극단적으로 좁힌다.** "9시에만 사람 있다"가 "언제 가도 아무도 없다"보다 훨씬 낫다.

### 4.3 장치

- **개장 알림** — PWA 푸시 / 이메일: `오늘 9시에 만나요`
- **개장 카운트다운** — 접속 시 `21:00 개장까지 12분`
- **프라임타임 한정** — 그 시간에만 열리는 랭킹전, 더블 점수
- **비프라임 시간** — 방 목록 대신 **데일리 싱글을 전면에** 배치 (§5)

### 4.4 개장 연출

9시 정각에 사람이 동시에 들어오게 만든다.

```
20:55  대기 로비 오픈. 들어온 사람들이 채팅으로 대기
21:00  방 자동 생성 + 일괄 배정
```

**대기 로비가 중요하다.** 5분 먼저 온 사람이 혼자 기다리다 나가지 않게, 대기 중에도 채팅이 돌게 한다.

## 5. 축 3 — 데일리 싱글

프라임타임이 아닌 시간이 하루의 대부분이다. **그 시간에 온 사람을 그냥 보내면 안 된다.**

| 항목 | 내용 |
|---|---|
| 게임 | 「그 해」 데일리 (혼자, 힌트 순차 공개, 6번 시도) |
| 소요 | 2분 |
| 빈도 | 하루 1회 |
| 기록 | 계정 있으면 저장, 연속 출석 스트릭 |

### 방으로 넘기는 다리

데일리를 끝낸 화면이 **방 유입의 주 경로**다.

```
┌────────────────────────────────────┐
│  오늘의 그 해  ✓ 3번 만에 정답!     │
│  ────────────────────────────────  │
│  지금 3번 방에 4명 있어요        │
│           [ 들어가기 ]              │
│                                    │
│  오늘 21:00 개장 (3시간 뒤)      │
│           [ 알림 받기 ]             │
└────────────────────────────────────┘
```

사람이 있으면 방으로, 없으면 알림 신청으로. **어느 쪽이든 그냥 나가지 않게 한다.**

## 6. 축 4 — 초대 우선

### 6.1 유입 단위가 다르다

데일리 게임은 개인이 유입되지만, 이 장르는 **무리로 유입된다.** 한 명이 단톡방에 코드를 던지면 5명이 들어온다. **그 순간 방이 완성된다.**

그래서 랜덤 매칭보다 초대가 먼저다.

### 6.2 마찰 제거

| 마찰 | 제거 |
|---|---|
| 가입 요구 | **게스트로 즉시 입장** (01 문서 §8) |
| 앱 설치 | 웹. 링크 누르면 바로 |
| 코드 입력 | 링크에 코드 포함 → 클릭 즉시 입장 |
| 방 찾기 | 링크가 방을 특정 |

**링크 클릭 → 3초 내 방 안.** 여기에 무엇도 끼워 넣지 않는다.

### 6.3 공유 최적화

- 카카오톡 OG 카드: `지금 3명이 기다려요 · 그때 3번 방`
- 링크 만료 없음 (방이 살아 있는 한)
- 방이 사라졌으면 → 방 목록으로 보내되 `그 방은 끝났어요. 다른 방 어때요?`

## 7. 축 5 — 뭉치기 압력

있는 사람이라도 흩어지면 안 된다.

| 장치 | 내용 |
|---|---|
| **빠른 입장** | 항상 **인원이 가장 많으면서 자리가 남은 방**으로 |
| 방 목록 정렬 | 인원 많은 순 (빈 방은 아래) |
| 방 생성 억제 | 입장 가능한 방이 있으면 `방 만들기` 대신 `3번 방에 들어가기` 를 먼저 제안 |
| 소규모 방 병합 | 2명 이하 방이 둘이면 합치기 제안 |
| 동시 방 수 상한 | `max(2, 동접 / 5)` 개로 제한 |

**마지막 항목이 반직관적이지만 중요하다.** 방을 무제한 만들게 두면 동접 20명이 방 10개에 2명씩 흩어진다.

## 8. 단계별 종합 전략

### Phase 1 — 동접 0~50 (생존)

```
프라임타임    하루 1시간 (21:00)
AI            적극 투입. 비율 50%+ 감수
유입          초대 링크 · 커뮤니티 시딩
비프라임      데일리 싱글 전면
방 수         최대 2~3개로 강제 집중
```

**목표: 21시에 방 2개가 사람으로 차는 것.** 그 이상은 안 본다.

### Phase 2 — 동접 50~300 (확장)

```
프라임타임    평일 2시간 + 주말 추가
AI            비율 30% 목표
유입          랜덤 매칭 도입, 결과 공유 확산
방 수         제한 완화
```

### Phase 3 — 동접 300+ (정상화)

```
프라임타임    상시 운영, 프라임타임은 이벤트 시간대로
AI            심야·비수기만. 비율 12%
유입          랭킹·시즌으로 자체 순환
```

## 9. 죽음의 나선 조기 경보

지표가 이 선을 넘으면 **즉시 Phase를 되돌린다.** 프라임타임을 다시 좁히고 AI를 더 넣는다.

| 지표 | 경보선 | 의미 |
|---|---|---|
| **신규 방문자가 사람 있는 방을 본 비율** | **< 50%** | 가장 중요. 첫인상이 빈 방이면 끝 |
| 평균 방 인원 | < 3.0 | 방이 흩어지고 있다 |
| AI 참가자 비율 | > 60% 지속 | 실제 유저가 안 늘고 있다 |
| 입장 후 1분 내 이탈률 | > 40% | 들어와서 실망하고 있다 |
| 프라임타임 피크 동접 | 전주 대비 -20% | 이탈이 시작됐다 |

**첫 번째 지표를 대시보드 맨 위에 둔다.** 이 하나가 프로젝트의 생사다.

## 10. 정직한 한계

이 문서의 장치들로도 **못 넘는 선이 있다.**

- **AI는 사람을 대체하지 못한다.** AI만 있는 방은 재미없고, 그건 실력 조절로 못 고친다
- 프라임타임 집중은 **모을 사람이 있을 때만** 유효하다. 0명을 모아도 0명이다
- 초대는 **첫 사용자가 있어야** 작동한다

즉 **초기 유저 100명을 어떻게 데려오느냐**는 이 문서 밖의 문제이고, 여전히 가장 어려운 문제다. 이 문서가 하는 일은 *데려온 사람을 잃지 않는 것*이다.

초기 유입 후보 (07 문서 마케팅과 연결):
- 90년대 향수 커뮤니티 · 카페에 직접 시딩
- 지인 단톡방 (가장 현실적인 첫 20명)
- 스트리머·유튜버에게 방 코드 제공 (시청자가 무리로 들어옴 — **이 장르에 가장 잘 맞는 채널**)
- 레트로 소재 콘텐츠로 SNS 유입 → 데일리 → 방

**스트리머 채널이 특히 유효하다.** 시청자 수백 명이 동시에 들어오면 그 순간 콜드스타트가 해결된다.

## 11. 열려 있는 결정 사항
