# 10. 진행 시스템 — 레벨 · 칭호 · 랭크

> 진행 축이 셋이다. **각각 다른 질문에 답한다.**

| 축 | 범위 | 성질 | 답하는 질문 |
|---|---|---|---|
| **레벨** | 1 ~ 100 | 누적. **떨어지지 않음** | "얼마나 했나" |
| **칭호** | 수십 종 | 수집 · 장착 | "뭘 했나" |
| **랭크** | 5급 ~ 유단자 | 시즌 리셋. 오르내림 | "얼마나 잘하나" |

셋을 섞지 않는 게 중요하다. 레벨이 실력을 뜻하면 오래 한 사람이 무조건 고수가 되고, 랭크가 안 떨어지면 경쟁이 성립하지 않는다.

---

## 1. 레벨 (1 ~ 100)

### 1.1 성격

- **플레이하면 무조건 오른다.** 이기든 지든, 캐주얼이든 랭크든
- **절대 떨어지지 않는다.** 랭크와의 결정적 차이
- 실력이 아니라 **누적 시간**을 나타낸다
- 프로필 · 방 목록 · 게임방 이름 옆에 항상 표시

**못하는 사람도 오르는 축이 하나는 있어야 한다.** 랭크만 있으면 하위권은 아무 성취감 없이 이탈한다.

### 1.2 경험치 획득

| 항목 | 경험치 |
|---|---|
| 판 완주 | +100 |
| 1등 | +150 |
| 2등 | +100 |
| 3등 | +70 |
| 4등 이하 | +40 |
| 정답 1개당 | +20 |
| 어시스트 1개당 (팀전) | +10 |
| **하루 첫 판** | **+200** |
| 데일리 싱글 완료 | +150 |

판당 평균 **약 500**. 하루 3판이면 1,700 정도.

**하루 첫 판 보너스가 크다.** 매일 오게 만드는 장치이고, 03 문서의 프라임타임과 맞물린다.

### 1.3 레벨 곡선

```
Lv  1 ~ 10    누적    3,000      약   6판    첫날
Lv 10 ~ 25    누적   20,000      약  40판    1주
Lv 25 ~ 45    누적   70,000      약 140판    1개월
Lv 45 ~ 70    누적  180,000      약 360판    3개월
Lv 70 ~ 90    누적  350,000      약 700판    7개월
Lv 90 ~ 100   누적  500,000      약 1,000판  1년
```

**초반은 빠르고 후반은 느리다.** 첫날 10레벨을 찍게 해서 진행감을 주고, 100레벨은 1년짜리 장기 목표로 남긴다.

필요 경험치 공식(초안): `xp(n) = round(40 × n^1.85)` — 실측 후 조정한다.
**레벨 곡선은 밸런싱 파라미터**로 DB에 두고 코드에 박지 않는다 (§5).

### 1.4 레벨 보상

| 주기 | 보상 |
|---|---|
| 매 레벨 | 레벨업 연출 + 프로필 숫자 갱신 |
| 5레벨마다 | **아바타 아이콘 해금** (06 문서 §4.3) |
| 10레벨마다 | **칭호 해금** (§2) |
| 특정 레벨 | 기능 해금 (§1.5) |

**게임 성능에 영향을 주는 보상은 없다.** 전부 장식과 기능 해금이다.

### 1.5 기능 해금

신규 유저를 압도하지 않으면서 할 게 늘어나는 감각을 준다.

| 레벨 | 해금 |
|---|---|
| 1 | 방 입장 · 캐주얼 플레이 · 데일리 싱글 |
| 3 | **방 만들기** |
| 8 | 팀전 |
| 15 | 커스텀 방 설정 (라운드 수 · 시간) |
| 20 | **랭크전 진입** ★ |
| 30 | 방 즐겨찾기 |
| 50 | 소재 연대 직접 선택 |

**랭크전을 Lv20에 잠가둔다.** 규칙을 모르는 사람이 랭크전에 들어와 팀을 망치는 걸 막고, 랭크의 무게감도 생긴다.

## 2. 칭호

### 2.1 성격

- 닉네임 앞에 **1개 장착**
- 수집은 무제한, 장착만 1개
- **획득 경로가 다양해야 한다.** 레벨만으로 주면 수집욕이 안 생긴다

```
[초딩] 감자탕러버        Lv 7
[연상왕] ㅋㅋ루삥뽕      Lv 42
[개근상] 야타족          Lv 63
```

### 2.2 레벨 칭호

**초딩 ~ 원로가 여기로 온다.** 랭크 티어가 아니라 레벨 칭호다.

| 칭호 | 레벨 | 아이콘 (Phosphor) |
|---|---|---|
| **초딩** | 1 ~ 9 | `backpack` |
| **중딩** | 10 ~ 24 | `notebook` |
| **고딩** | 25 ~ 44 | `books` |
| **대딩** | 45 ~ 69 | `guitar` |
| **아재 / 이모** | 70 ~ 89 | `coffee` |
| **원로** | 90 ~ 100 | `crown` |

- 상위 칭호를 얻어도 **하위 칭호는 그대로 보유**한다. 낮은 걸 일부러 달 수도 있다 — `[초딩]` 달고 고수인 게 재밌다
- 아재/이모는 성별 선택 시에만 갈린다. 미선택이면 `아재` (08 문서 P6)

**"아재"가 최상위 직전이라는 게 이 게임에 딱 맞는다.** 나이를 자랑거리로 만든다.

### 2.3 업적 칭호

수집의 본체. **레벨과 무관하게** 특정 행동으로 얻는다.

| 칭호 | 조건 |
|---|---|
| `연상왕` | 단어 연상 출제자로 200점 이상 10회 |
| `초성장인` | 초성 퀴즈 500회 정답 |
| `연도감별사` | 「그 해」 첫 힌트에 정답 30회 |
| `개근상` | 30일 연속 접속 |
| `관종` | 누적 채팅 10,000회 |
| `눈치백단` | 2등 100회 |
| `묻어가기` | 팀전 어시스트 300회 |
| `자정근무` | 새벽 2~5시 100판 |
| `첫차` | 하루 첫 판 300회 |
| `단골` | 같은 방 50회 입장 |
| `호구` | 오답 1,000회 |
| `무한도전` | 한 세션 10판 연속 |

**`호구` 같은 자조적 칭호를 넣는다.** 잘한 것만 칭호로 주면 하위권이 가질 게 없다. 오히려 이런 게 인기 있다.

### 2.4 랭크 칭호

시즌 종료 시 도달 티어에 따라 **영구 지급**. 시즌이 리셋돼도 칭호는 남는다.

```
[S1 1급]   [S1 유단자]   [S2 3급]
```

시즌 상위 10명은 `[S1 명예의전당]`.

### 2.5 이벤트 칭호

기간 한정. 재획득 불가 → 희소성.

```
[베타테스터]   [1주년]   [설날2027]
```

**`[베타테스터]`를 초기 유저에게 준다.** 콜드스타트 시기에 들어와준 사람들에 대한 보상이고, 나중에 이게 자랑거리가 된다 (03 문서).

## 3. 랭크

### 3.1 두 갈래

| | 데일리 랭킹 | 랭크전 (급/단) |
|---|---|---|
| 기반 | **싱글 데일리** | **멀티 랭크전** |
| 동기성 | 비동기 | 동기 (4명 필요) |
| 필요 인원 | **0명** | 4명 |
| 리셋 | 매일 | 시즌 (3개월) |
| 도입 | **Phase 1** | Phase 3 |

**데일리 랭킹을 먼저 만든다.** 콜드스타트 시기에도 작동하는 유일한 경쟁 장치다.

### 3.2 데일리 랭킹 (싱글 기반)

```
매일 00:00 KST — 게임 3종 각각 오늘의 문제 확정 (전원 동일)
  ↓  하루 중 아무때나 1회 플레이
점수 → 일간 리더보드 → 다음날 리셋 (주간 누적은 별도)
```

| 게임 | 형태 | 점수 |
|---|---|---|
| **그 해** | 힌트 순차 공개, 6번 시도 | 적게 쓸수록 고득점 (1번 1000 → 6번 200) |
| **초성 퀴즈** | 60초 타임어택, 20문제 | 정답 수 × 속도 보너스 |
| **단어 연상** | AI 출제자와 1:1, 5단어 | 맞힌 수 × 남은 시간 |

```
┌──────────────────────────────┐
│  오늘의 랭킹 · 그 해          │
├──────────────────────────────┤
│  1위  [연상왕] 야타족    1000 │
│  2위  [개근상] ㅋㅋ루삥뽕 800 │
│  3위  [초딩] 감자탕러버   620 │
│  ─────────────────────────   │
│  나   ⑫위  620               │  ← 항상 내 순위
│  친구 중 2위                  │
└──────────────────────────────┘
```

**"친구 중 2위"가 전체 1000위보다 동기부여가 크다.** 작은 모수의 순위를 우선 보여준다.

게스트는 플레이는 되지만 랭킹에 안 들어간다. 결과 화면에서 유도한다:

```
당신의 620점은 오늘 12위에 해당해요.   [ 기록 남기기 ]
```

**점수를 먼저 보여주고 가입을 권한다.** 순서가 반대면 안 한다.

### 3.3 랭크전

캐주얼방과 분리된 **매칭 기반 경쟁 모드**. Lv20부터 진입 가능.

| | 캐주얼방 | 랭크전 |
|---|---|---|
| 입장 | 목록 · 코드 · 빠른입장 | **매칭 큐만** ★ |
| 인원 | 2~8명 | **4명 고정** |
| 라운드 | 방장이 선택 | 10 고정 |
| 게임 | 방장이 선택 | 랜덤 또는 시즌 지정 |
| AI 참가자 | 있음 | **없음** ★ |
| 팀전 | 가능 | **개인전 고정** |
| 채팅 | 자유 | 이모트만 |
| 중도 이탈 | 자유 | 패널티 |

**랭크전에 AI를 넣지 않는다.** 경쟁의 공정성이 흔들리면 랭크의 의미가 없다. 대신 4명이 안 모이면 매칭이 안 된다 — 그래서 동접이 필요하고 Phase 3인 것이다.

### 3.4 승점

```
4인 랭크전 1판

1등  +30      2등  +12
3등   -4      4등  -12
이탈  -25
```

**3·4등의 손실을 작게 잡는다.** 캐주얼 게임에서 크게 잃으면 그냥 안 한다. 올라가는 맛은 있되 떨어지는 고통은 약하게.

연승 보너스: 3연속 1~2등이면 +5.

### 3.5 티어 — 급/단 체계

학력 이름은 칭호로 갔으므로(§2.2), 랭크는 **급/단**으로 간다. 한국인에게 서열이 즉시 읽히고, 레트로하지도 촌스럽지도 않다.

| 티어 | 승점 | 아이콘 |
|---|---|---|
| **5급** | 0 ~ 299 | `circle` |
| **4급** | 300 ~ 699 | `circle-half` |
| **3급** | 700 ~ 1199 | `circles-three` |
| **2급** | 1200 ~ 1799 | `diamond` |
| **1급** | 1800 ~ 2499 | `diamonds-four` |
| **유단자** | 2500 + | `star` |

유단자는 승점에 따라 **초단 ~ 9단**으로 세분한다 (상위권 전용 눈금).

- 티어 강등은 **한 단계까지만** (연속 강등 없음)
- 승격 시 이펙트 + 공유 카드
- 프로필 · 방 목록 · 게임방에 뱃지 표시

> 대안 후보: `동네오락실 → 시내오락실 → 전국구 → 전설`. 레트로 색이 더 진하지만 서열 직관성이 떨어진다. 급/단으로 확정하되 베타에서 반응을 본다 (§8 P2).

### 3.6 시즌

| 항목 | 값 |
|---|---|
| 기간 | 3개월 |
| 리셋 | 승점의 **50%만 이월** (완전 리셋은 이탈 유발) |
| 보상 | 시즌 칭호 (영구), 프로필 프레임, 아바타 아이콘 |
| 명예의 전당 | 시즌별 상위 10명 영구 기록 |

**보상은 전부 장식이다.**

### 3.7 매칭

```
큐 진입 → 같은 티어 ±1 우선, 30초 대기
       → 안 되면 티어 범위 확대
       → 60초 초과: "지금은 사람이 적어요. 캐주얼방 어때요?"
```

**매칭 실패를 막다른 길로 만들지 않는다.**

### 3.8 콜드스타트 대응

랭크전은 **4명 동시**가 필요해 가장 취약하다 (03 문서).

| 장치 | 내용 |
|---|---|
| **프라임타임 한정** | 초기엔 21:00~22:00에만 큐를 연다 |
| 티어 무시 매칭 | 동접이 적으면 범위를 즉시 무제한으로 |
| 큐 인원 표시 | `지금 랭크 큐에 6명` |
| 캐주얼 유도 | 매칭 실패 시 |
| **도입 지연** | **동접 300 이상**일 때 정식 오픈 |

**동접이 부족한데 랭크전을 열면 빈 큐만 보여주고 실망시킨다.** 차라리 늦게 여는 게 낫다.

## 4. 세 축의 관계

```
              플레이
                │
      ┌─────────┼─────────┐
      ▼         ▼         ▼
    레벨      칭호       랭크
      │         ▲         │
   누적 XP      │      승점 ± 
      │         │         │
  안 떨어짐     │     시즌 리셋
      │         │         │
      └─────────┴─────────┘
        레벨·업적·랭크·이벤트
        모두가 칭호의 공급원
```

- 레벨이 오르면 **칭호가 해금**된다
- 랭크 시즌이 끝나면 **칭호가 지급**된다
- **칭호가 세 축을 잇는 허브다**

### 화면 표기

```
[연상왕] ㅋㅋ루삥뽕   Lv42   2급
   칭호     닉네임    레벨   랭크
```

방 목록 · 게임방은 공간이 없으므로 **칭호 + 닉네임**만, 프로필에서 전부 보여준다.

## 5. 데이터

```sql
CREATE TABLE user_progress (
  user_id     UUID PRIMARY KEY,
  level       SMALLINT DEFAULT 1,
  xp          BIGINT DEFAULT 0,           -- 누적
  xp_to_next  INTEGER,                     -- 캐시
  title_id    TEXT,                        -- 장착 칭호
  updated_at  TIMESTAMPTZ
);

CREATE TABLE titles (                       -- 마스터
  id          TEXT PRIMARY KEY,             -- 'level_ajae' | 'ach_yeonsangwang'
  name        TEXT NOT NULL,
  kind        TEXT NOT NULL,                -- level|achievement|rank|event
  icon        TEXT,
  condition   JSONB NOT NULL,
  hidden      BOOLEAN DEFAULT FALSE
);

CREATE TABLE user_titles (
  user_id     UUID,
  title_id    TEXT REFERENCES titles(id),
  earned_at   TIMESTAMPTZ,
  PRIMARY KEY (user_id, title_id)
);

CREATE TABLE level_curve (                  -- ★ 밸런싱 파라미터
  level       SMALLINT PRIMARY KEY,
  xp_required INTEGER NOT NULL,
  reward      JSONB                         -- 해금 아이콘 · 칭호 · 기능
);

CREATE TABLE daily_scores (
  game_id   TEXT, date DATE, user_id UUID,
  score     INTEGER NOT NULL,
  detail    JSONB,
  played_at TIMESTAMPTZ,
  PRIMARY KEY (game_id, date, user_id)
);
CREATE INDEX ON daily_scores (game_id, date, score DESC);

CREATE TABLE rank_profiles (
  user_id     UUID PRIMARY KEY,
  season      TEXT NOT NULL,
  points      INTEGER DEFAULT 0,
  tier        TEXT,                         -- g5|g4|g3|g2|g1|dan
  dan         SMALLINT,                     -- 유단자만 1~9
  peak_points INTEGER DEFAULT 0,
  wins        INTEGER DEFAULT 0,
  played      INTEGER DEFAULT 0
);

CREATE TABLE season_hall (
  season TEXT, rank SMALLINT, user_id UUID, points INTEGER,
  PRIMARY KEY (season, rank)
);
```

**`level_curve`를 테이블로 둔다.** 밸런싱을 코드 배포 없이 조정하기 위해서다.

## 6. 안티치트

| 위협 | 방어 |
|---|---|
| 데일리 재도전 | 계정당 1회 (`daily_scores` UNIQUE) |
| **경험치 파밍** (판 만들고 즉시 종료) | 완주 판정 — 최소 라운드 수 · 최소 참여 |
| AI만 넣고 반복 | **AI 비율이 높은 판은 경험치 50% 감산** |
| 다중 계정 | 계정 필수 + Turnstile + 이상 패턴 탐지 |
| **승부 조작** | 랭크전은 **매칭으로만** 입장. 방 코드 불가 ★ |
| 이탈 반복 | 패널티 + 반복 시 큐 진입 제한 |

**★ 표시가 핵심이다.** 친구끼리 방을 만들어 점수를 몰아주는 걸 막으려면 랭크전에 방 코드 입장을 아예 없애야 한다.

### 팀 랭크를 만들지 않는 이유

팀전은 캐주얼방 옵션으로만 제공하고 **랭크전은 개인전 고정**이다. 팀 랭크는 4명이 짜고 두 명씩 팀을 먹은 뒤 한쪽이 져주면 점수를 마음대로 옮길 수 있다. Phase 4 이후 동접이 충분해진 다음에 검토한다.

## 7. 도입 시점

| Phase | 진행 시스템 |
|---|---|
| **1** | **레벨 1~100 + 레벨 칭호 + 데일리 랭킹** |
| **2** | 업적 칭호, 주간·친구·세대별 랭킹, 기능 해금 |
| **3** | **랭크전 + 급/단 + 시즌 + 랭크 칭호** (동접 300 이상) |
| **4** | 히든 칭호, 시즌 보상 확대, 명예의 전당, 팀 랭크 검토 |

**레벨은 MVP에 반드시 넣는다.** 사람이 없는 초기에도 "뭔가 쌓인다"는 감각이 유일한 잔류 이유가 된다.
