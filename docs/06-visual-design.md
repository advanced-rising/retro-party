# 06. 비주얼 디자인

> **모던 다크 캐주얼 + 레트로 악센트.**
> 이전 기획의 PC통신 터미널 UI는 폐기한다. 향수는 UI가 아니라 **콘텐츠**에서 나온다.

## 1. 방향 전환 — 왜 터미널을 버렸나

| 문제 | |
|---|---|
| **정보 밀도** | 방 목록 · 참가자 · 점수판 · 채팅 · 타이머를 동시에 보여줘야 하는데 문자 그리드로는 불가능 |
| **모바일** | 80칸 터미널은 세로 화면에서 무너진다. 이 장르는 모바일 비중이 크다 |
| **속도감** | 실시간 게임에는 부드러운 모션이 필요한데 터미널 감성과 충돌 |
| **진입 장벽** | 20대에게 터미널은 향수가 아니라 그냥 불편함 |

**향수는 어디서 오나**: 힌트가 `자장면 한 그릇 2,500원`이고 단어가 `삐삐`면 그걸로 충분하다. 오히려 UI가 깔끔할수록 콘텐츠의 옛날 냄새가 더 선명해진다.

> **레트로는 향신료지 주재료가 아니다.** 로고와 큰 숫자에만 도트를 남긴다.

## 2. 컬러

다크 베이스 + 라임 액센트. 실시간 게임의 에너지를 라임이 담당한다.

```css
:root {
  /* 배경 */
  --bg-base:      #0D0F14;
  --bg-surface:   #161A22;   /* 카드 */
  --bg-elevated:  #1E232D;   /* 호버 · 활성 */
  --bg-overlay:   rgb(13 15 20 / 0.82);

  /* 선 */
  --border:       #2A303C;
  --border-hi:    #3D4757;

  /* 텍스트 */
  --text-hi:      #F2F4F8;
  --text:         #C6CCD6;
  --text-lo:      #8A94A3;
  --text-dim:     #5C6675;

  /* 시맨틱 */
  --lime:         #7CFF6B;   /* 정답 · 성공 · 주 CTA */
  --blue:         #5B9DFF;   /* 정보 · 내 차례 */
  --amber:        #FFB84D;   /* 시간 부족 */
  --red:          #FF5C5C;   /* 오답 · 위험 */
  --gold:         #FFD65C;   /* 1등 */
  --purple:       #B388FF;   /* ★ AI 참가자 */
}
```

### 사용 규칙

- **라임은 정답과 주 CTA에만.** 남발하면 정답의 쾌감이 죽는다
- **보라(`--purple`)는 AI 참가자 전용.** 03 문서의 "숨기지 않는다" 원칙을 색으로 구현한다. 아바타 링 · 닉네임 · `🤖` 배지가 모두 보라
- 금색은 결과 화면 1등에만
- 색만으로 정보를 전달하지 않는다 — 아이콘·텍스트 병기

### 라이트 모드

**만들지 않는다.** 실시간 파티 게임은 다크가 기본이고, 다크만 잘 만드는 게 둘 다 어중간한 것보다 낫다.

## 3. 타이포그래피

| 용도 | 폰트 | 라이선스 |
|---|---|---|
| 본문 · UI 전체 | **Pretendard Variable** | SIL OFL 1.1 ✅ |
| 숫자 (점수 · 타이머) | Pretendard + `tabular-nums` | — |
| **레트로 악센트** | **Galmuri11 / Galmuri14** | SIL OFL 1.1 ✅ |

Pretendard는 한국 웹의 사실상 표준이고, 가변 폰트라 굵기 조절이 자유롭다.

### Galmuri를 쓰는 곳 — 딱 네 군데

1. 로고 `그때`
2. 라운드 번호 `R4/10`
3. 「그 해」 정산 카드의 큰 연도 `1997`
4. 결과 화면 최종 점수

**그 외에는 절대 쓰지 않는다.** 도트 폰트가 본문에 들어가면 가독성이 무너지고 촌스러워진다.

```css
.font-retro { font-family: 'Galmuri14', monospace; }
.num        { font-variant-numeric: tabular-nums; }
```

### 스케일

```
display   40px / 700 / -0.02em    결과 점수, 정산 연도
h1        28px / 700
h2        20px / 600
body      15px / 400 / 1.6
small     13px / 400
caption   11px / 500 / +0.02em    라벨, 배지
```

## 4. ★ 에셋 소스 — 검증된 오픈소스에서 가져온다

아이콘을 직접 그리지 않는다. **유명하고 라이선스가 깨끗한 것만** 쓴다.

### 4.1 아이콘

| 라이브러리 | 용도 | 라이선스 | 비고 |
|---|---|---|---|
| **Lucide** ⭐ | UI 아이콘 전반 | **ISC** | React 컴포넌트 제공, shadcn/ui 기본. 1,500+ |
| **Phosphor Icons** | Lucide에 없는 것 | **MIT** | 9,000+, 6가지 굵기 |
| Tabler Icons | 예비 | MIT | 5,900+ |
| Simple Icons | 브랜드 로고 (카카오·구글 로그인) | **CC0 1.0** | |

**Lucide를 기본으로 하고 없는 것만 Phosphor에서 가져온다.** 두 세트를 섞어도 선 굵기가 비슷해 위화감이 적다 — 단 `strokeWidth`를 `1.75`로 통일한다.

필요 아이콘 예: `users` `clock` `trophy` `crown` `check` `x` `send` `link` `door-open` `bot` `flame` `zap` `message-circle` `volume-2` `settings`

### 4.2 이모지 — 아바타 · 이모트

| 후보 | 라이선스 | 판단 |
|---|---|---|
| **Noto Emoji** ⭐ | **SIL OFL 1.1** | 출처 표시 부담 없음. 폰트로 임베드 |
| Twemoji | 그래픽 **CC-BY 4.0** / 코드 MIT | 더 친숙하나 **출처 표시 의무** |
| OpenMoji | CC BY-SA 4.0 | SA 조항 부담 |
| 시스템 기본 | — | 라이선스 무관하나 **OS마다 달라 보인다** |

**Noto Emoji 채택.** 아바타가 기기마다 다르면 안 되고, OFL이라 고지 부담이 적다.

아바타는 **이모지 하나 + 배경색**으로 만든다. 별도 캐릭터 아트가 필요 없다.

```
🥔 감자탕러버   배경 #2A3140
🌀 ㅋㅋ루삥뽕   배경 #2A2140
🤖 96학번       배경 보라 계열 (AI)
```

### 4.3 사운드 · 픽셀 악센트

| 소스 | 라이선스 | 용도 |
|---|---|---|
| **Kenney Audio Packs** ⭐ | **CC0 1.0** | UI 클릭, 정답/오답, 카운트다운 |
| Kenney 1-Bit Pack | CC0 1.0 | 레트로 픽셀 아이콘 악센트 |

**Kenney는 게임 에셋의 표준이다.** CC0라 출처 표시조차 필요 없고 품질이 일정하다.

필요 사운드 7종: 입장 · 정답 · 오답 · 라운드 시작 · 카운트다운 · 결과 발표 · 이모트.
**기본 OFF.** 자동재생 소리는 즉시 이탈 요인이다.

| | 선택 | 라이선스 |
|---|---|---|

### 4.5 라이선스 관리

```
docs/ASSETS.md 에 전부 기록
  · 라이브러리명 · 버전 · 라이선스 · 출처 URL · 사용 범위

### 채팅은 말풍선이 아니라 라인형

```

🌀 ㅋㅋ루삥뽕   아니 더 뒤일걸

말풍선은 세로 공간을 많이 먹는다. **정보 밀도가 우선**이라 Discord·Skribbl 방식의 라인형으로 간다. 정답만 라임 배경으로 강조.

## 7. 모션

**Framer Motion 스프링** 기반. `duration` 이징보다 캐주얼 게임에 어울린다.

| 동작 | 스펙 |
|---|---|
| 정답 인정 | 채팅 라인 `scale 1 → 1.04 → 1` + 라임 글로우, 200ms |
| 점수 증가 | 숫자 롤업 400ms + `+100` 플로팅 상승 |
| 새 채팅 | `y +8 → 0` + fade in, 150ms |
| 라운드 전환 | 전체 오버레이 `R5` 카운트, 1.2s |
| 참가자 입장 | 아바타 `scale 0.8 → 1` + fade, 250ms |
| 타이머 경고 | 5초 이하 숫자 확대 + 미세 진동 |
| 결과 순위 | 1등부터 순차 등장, 120ms 간격 |

### 예산

**라운드 전환 총 1.5초를 넘기지 않는다.** 10라운드면 전환만 15초다. 연출을 늘리려면 다른 걸 줄인다.

`prefers-reduced-motion` 존중 — 모든 스프링을 즉시 전환으로.

## 8. 모바일

이 장르는 모바일 비중이 크다. **모바일이 1급 시민이다.**

| 항목 | 처리 |
|---|---|
| **키보드 가림** | `visualViewport` API로 입력창을 키보드 위에 고정. **가장 흔한 버그이자 치명적** |
| 안전 영역 | `env(safe-area-inset-bottom)` |
| 터치 타겟 | 최소 48×48 |
| 이모트 버튼 | 입력창 옆 고정. 타이핑 느린 사람의 참여 수단 |
| 가로 모드 | 지원하되 최적화는 안 함 |
| PWA | 홈 화면 추가 + 푸시 (03 문서 프라임타임 알림) |

**키보드 가림 문제를 초기에 잡는다.** 채팅이 입력 장치인 게임에서 입력창이 가려지면 게임이 안 된다.

## 9. 접근성

| 항목 | 처리 |
|---|---|
| 대비 | 본문 WCAG AA (4.5:1) 이상. `--text-dim`은 캡션에만 |
| 색 의존 금지 | 정답 = 라임 + `✓` + `+100` 텍스트 |
| AI 표시 | 보라 + `🤖` + 스크린리더용 "AI 참가자" |
| 키보드 | 전 기능 조작. 채팅 입력에 항상 포커스 |
| 스크린리더 | 채팅 `aria-live="polite"`, 정답은 `assertive` |
| 모션 | `prefers-reduced-motion` |
| 시간 압박 | 방장이 라운드 시간을 늘릴 수 있게 (느긋 모드) |
| 광과민성 | 3Hz 이상 전체 화면 깜빡임 금지 |
