# 06. 비주얼 디자인

> **모던 다크 캐주얼 + 레트로 악센트.**
> 이전 기획의 PC통신 터미널 UI는 폐기한다. 향수는 UI가 아니라 **콘텐츠**에서 나온다.

## 1. 방향 전환 — 왜 터미널을 버렸나

| 문제 | |
|---|---|
| **정보 밀도** | 방 목록 · 참가자 · 점수판 · 채팅 · 타이머를 동시에 보여줘야 하는데 문자 그리드로는 불가능 |
| **모바일** | 80칸 터미널은 세로 화면에서 무너진다. 이 장르는 모바일 비중이 크다 |
| **속도감** | 실시간 게임에는 부드러운 모션이 필요한데 터미널 감성과 충돌 |
| **진입 장벽** | 20대에게 터미널은 향수가 아니라 그냥 불편함 |

**향수는 어디서 오나**: 힌트가 `자장면 한 그릇 2,500원`이고 단어가 `삐삐`면 그걸로 충분하다. 오히려 UI가 깔끔할수록 콘텐츠의 옛날 냄새가 더 선명해진다.

> **레트로는 향신료지 주재료가 아니다.** 로고와 큰 숫자에만 도트를 남긴다.

## 2. 컬러 — 네온 라임 / 다크 · 라이트

**다크가 기본이고 라이트도 정식 지원한다.** 시스템 설정을 따라가되 미설정이면 다크로 떨어진다.
실시간 파티 게임은 저녁·밤 사용이 압도적이고, 03 문서의 프라임타임(21시)이 그 시간대다.

### 2.1 ★ 규칙 하나 — 라이트에는 네온이 없다

`#7CFF6B`를 흰 배경에 글자로 올리면 대비가 **1.4:1**이다. 안 읽힌다.

**액센트는 테마에 따라 명도가 뒤집히고, 그 위에 얹는 글자색도 같이 뒤집힌다.**

| | 다크 | 라이트 |
|---|---|---|
| `--lime` | `#7CFF6B` (네온) | `#1B7A10` (딥 그린) |
| `--on-lime` | `#07240A` (어두운 글자) | `#FFFFFF` (흰 글자) |

- **다크**: 어두운 바탕에서 라임이 밝은 전경. 텍스트·아이콘·바에 같은 값. 버튼만 라임이 면이 되므로 글자를 어둡게
- **라이트**: 흰 바탕에서 딥 그린이 전경. 버튼은 그 색이 면이 되므로 글자를 흰색으로

**토큰은 색마다 하나면 된다.** 컴포넌트는 테마를 몰라도 된다.

### 2.3 대비 — 눈으로 판단하지 않는다

본문 **4.5:1**(WCAG AA), 바·아이콘 등 비텍스트 **3:1**(WCAG 1.4.11).
배경은 각 테마의 **가장 불리한 표면**(`--bg-elevated`)으로 계산한다.


### 2.4 사용 규칙

- **`--text-dim`보다 흐린 글자를 만들지 않는다.** 네 단계(hi/기본/lo/dim)가 회색 텍스트의 전부이고 dim이 AA 하한선이다. 더 흐리게 하고 싶으면 색이 아니라 **크기·굵기**로 위계를 만든다
- **라임은 세 자리에만** — 타이머 바 · 정답 하이라이트 · 주 버튼.
  네 번째 자리를 만들고 싶어지면 그건 라임이 아니라 다른 토큰이 필요한 것이다.
  **정답의 쾌감은 라임이 희소할 때만 생긴다**
- **`--purple`은 출제자 전용.** 단어 연상에서 지금 설명하는 사람이 누구인지 한눈에 보여야 한다. 라이트에서 반드시 어두워져야 하고, 여기 말고 다른 곳에 쓰면 그 신호가 죽는다
- **색만으로 정보를 전달하지 않는다** — 정답은 `--lime` + `check-circle` 아이콘 + `+100` 텍스트

### 2.5 두 테마의 깊이 표현

| | 다크 | 라이트 |
|---|---|---|
| 카드 구분 | **그림자** `0 18px 46px -26px` | **1px 보더** `--border` |
| 계층 | 표면을 밝게 (`--bg-elevated`) | 표면을 희게 + 보더 |

**라이트에서 그림자를 쓰지 않는다.** 다크용 그림자를 그대로 얹으면 뿌옇고 지저분해진다.

### 2.6 타이머 색 전환

라운드 타이머는 남은 시간에 따라 색이 바뀐다. **라임이 일하는 가장 중요한 자리다.**

```
잔여 100~15%   --lime
잔여  15~5%    --amber
잔여   5~0%    --red    + 숫자 확대 + 미세 진동
```

## 3. 타이포그래피

| 용도 | 폰트 | 라이선스 |
|---|---|---|
| 본문 · UI 전체 | **Pretendard Variable** | SIL OFL 1.1 ✅ |
| 숫자 (점수 · 타이머) | Pretendard + `tabular-nums` | — |
| **레트로 악센트** | **Galmuri11 / Galmuri14** | SIL OFL 1.1 ✅ |

Pretendard는 한국 웹의 사실상 표준이고, 가변 폰트라 굵기 조절이 자유롭다.

### Galmuri를 쓰는 곳 — 딱 네 군데

1. 로고 `그때`
2. 라운드 번호 `R4/10`
3. 「그 해」 정산 카드의 큰 연도 `1997`
4. 결과 화면 최종 점수

**그 외에는 절대 쓰지 않는다.** 도트 폰트가 본문에 들어가면 가독성이 무너지고 촌스러워진다.

```css
.font-retro { font-family: 'Galmuri14', monospace; }
.num        { font-variant-numeric: tabular-nums; }
```

## 4. ★ 에셋 소스 — 검증된 오픈소스에서 가져온다

아이콘을 직접 그리지 않는다. **유명하고 라이선스가 깨끗한 것만** 쓴다.

### 4.1 아이콘

| 라이브러리 | 용도 | 라이선스 | 비고 |
|---|---|---|---|
| **Lucide** ⭐ | UI 아이콘 전반 | **ISC** | React 컴포넌트 제공, shadcn/ui 기본. 1,500+ |
| **Phosphor Icons** | Lucide에 없는 것 | **MIT** | 9,000+, 6가지 굵기 |
| Tabler Icons | 예비 | MIT | 5,900+ |
| Simple Icons | 브랜드 로고 (카카오·구글 로그인) | **CC0 1.0** | |

**Lucide를 기본으로 하고 없는 것만 Phosphor에서 가져온다.** 두 세트를 섞어도 선 굵기가 비슷해 위화감이 적다 — 단 `strokeWidth`를 `1.75`로 통일한다.

필요 아이콘 예: `users` `clock` `trophy` `crown` `check` `x` `send` `link` `door-open` `bot` `flame` `zap` `message-circle` `volume-2` `settings`

### 4.2 ★ 이모지를 사용하지 않는다

**UI 어디에도 이모지를 쓰지 않는다.** 아바타 · 순위 · 상태 · 이모트 전부 아이콘 또는 텍스트로 처리한다.

| 이모지를 쓰지 않는 이유 | |
|---|---|
| **OS·브라우저마다 다르게 보인다** | 같은 아바타가 기기마다 다른 그림이 된다 |
| **톤이 안 맞는다** | 컬러풀한 이모지가 다크 UI의 절제된 톤을 깬다 |
| 크기·정렬이 제각각 | 라인 높이가 튀어 채팅 목록이 흔들린다 |
| 색을 통제할 수 없다 | 팀 색·출제자 보라 같은 시맨틱 컬러를 못 입힌다 |
| 접근성 | 스크린리더가 읽는 이름이 제각각 |

아이콘은 **단색이라 색을 마음대로 입힐 수 있다.** 청팀 아바타는 파랑, 홍팀은 빨강, 출제자는 보라 — 이모지로는 불가능한 일관성이다.

### 4.3 아바타 — 90년대 물건 아이콘

```
아바타 = Phosphor Fill 아이콘 1개  +  배경색 1개
         (60종)                      (12색)
       = 720 조합
```

**아이콘을 90년대 물건으로 고른다.** 이게 이 게임의 정체성이 된다.

| 계열 | Phosphor 아이콘 |
|---|---|
| **90년대 물건** ★ | `cassette-tape` `floppy-disk` `television` `game-controller` `telephone` `boombox` `vinyl-record` `camera` `radio` `disc` |
| 사물 | `rocket` `guitar` `headphones` `coffee` `pizza` `crown` `key` `bell` `gift` `anchor` |
| 자연 | `cactus` `leaf` `mountains` `moon` `sun` `cloud` `flame` `drop` `star` `snowflake` |
| 동물 | `cat` `dog` `bird` `fish` `butterfly` `horse` `cow` `paw-print` |
| 기호 | `diamond` `heart` `lightning` `ghost` `smiley` `eye` `hand-peace` `sparkle` |
| AI 전용 | `robot` (보라 고정, 다른 참가자는 못 씀) |

```
◆ 감자탕러버    cassette-tape   배경 #2A3140
◆ ㅋㅋ루삥뽕    game-controller 배경 #2A2140
◆ 야타족        vinyl-record    배경 #1F3328
◆ 야옹이        floppy-disk     배경 #33281F
```

- 가입 시 랜덤 배정, 프로필에서 변경 가능
- 같은 방에 같은 조합이 겹치지 않게 배정
- **출제자는 아바타 테두리가 `--purple` 로 바뀐다** (단어 연상). 아이콘 자체는 그대로 두고 테두리만 바꿔서, 누가 출제 중인지가 아바타 정체성을 덮지 않게 한다

### 채팅은 말풍선이 아니라 라인형

```
◆ 감자탕러버   1996?
◆ ㅋㅋ루삥뽕   아니 더 뒤일걸
◆ 야타족       1997          ✓ +100
```

말풍선은 세로 공간을 많이 먹는다. **정보 밀도가 우선**이라 Discord·Skribbl 방식의 라인형으로 간다. 정답만 라임 배경으로 강조.

## 7. 모션

**Framer Motion 스프링** 기반. `duration` 이징보다 캐주얼 게임에 어울린다.

| 동작 | 스펙 |
|---|---|
| 정답 인정 | 채팅 라인 `scale 1 → 1.04 → 1` + 라임 글로우(다크만), 200ms |
| 점수 증가 | 숫자 롤업 400ms + `+100` 플로팅 상승 |
| 새 채팅 | `y +8 → 0` + fade in, 150ms |
| 라운드 전환 | 전체 오버레이 `R5` 카운트, 1.2s |
| 참가자 입장 | 아바타 `scale 0.8 → 1` + fade, 250ms |
| 타이머 경고 | 5초 이하 숫자 확대 + 미세 진동 |
| 결과 순위 | 1등부터 순차 등장, 120ms 간격 |

### 예산

**라운드 전환 총 1.5초를 넘기지 않는다.** 10라운드면 전환만 15초다. 연출을 늘리려면 다른 걸 줄인다.

`prefers-reduced-motion` 존중 — 모든 스프링을 즉시 전환으로.

## 8. 모바일

이 장르는 모바일 비중이 크다. **모바일이 1급 시민이다.**

| 항목 | 처리 |
|---|---|
| **키보드 가림** | `visualViewport` API로 입력창을 키보드 위에 고정. **가장 흔한 버그이자 치명적** |
| 안전 영역 | `env(safe-area-inset-bottom)` |
| 터치 타겟 | 최소 48×48 |
| 이모트 버튼 | 입력창 옆 고정. 타이핑 느린 사람의 참여 수단 |
| 가로 모드 | 지원하되 최적화는 안 함 |
| PWA | 홈 화면 추가 + 푸시 (03 문서 프라임타임 알림) |

**키보드 가림 문제를 초기에 잡는다.** 채팅이 입력 장치인 게임에서 입력창이 가려지면 게임이 안 된다.

## 9. 접근성

| 항목 | 처리 |
|---|---|
| 대비 | 본문 WCAG AA (4.5:1) 이상. `--text-dim`은 캡션에만 |
| 색 의존 금지 | 정답 = 라임 + `✓` + `+100` 텍스트 |
| 출제자 표시 | 보라 테두리 + `microphone-stage` + 스크린리더용 "출제자" |
| 키보드 | 전 기능 조작. 채팅 입력에 항상 포커스 |
| 스크린리더 | 채팅 `aria-live="polite"`, 정답은 `assertive` |
| 모션 | `prefers-reduced-motion` |
| 시간 압박 | 방장이 라운드 시간을 늘릴 수 있게 (느긋 모드) |
| 광과민성 | 3Hz 이상 전체 화면 깜빡임 금지 |
