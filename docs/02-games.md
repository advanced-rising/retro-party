# 02. 게임 3종

> 방 껍데기는 01 문서. 여기는 그 안에서 도는 게임들이다.
> 세 게임 모두 **채팅으로 답을 외친다**는 점이 같고, 콘텐츠 조달 방식이 다르다.

| 게임 | 형태 | 최소 인원 | 라운드 | 콘텐츠 출처 |
|---|---|---|---|---|
| **그 해** | 힌트 순차 공개 → 연도 맞히기 | 2 | 60초 | 사전 구축 DB (04 문서) |
| **초성 퀴즈** | 초성 + 카테고리 → 단어 맞히기 | 2 | 20초 | 사전 구축 DB |
| **단어 연상** | 출제자가 설명 → 나머지가 맞히기 | 3 | 90초 | **사람이 만든다** |

## 1. 그 해

### 1.1 라운드 구조

```
[0s]   라운드 시작. 힌트 1 공개
[8s]   힌트 2 공개
[16s]  힌트 3 공개
[24s]  힌트 4 공개
[32s]  힌트 5 공개
[40s]  힌트 6 공개  ← 거의 정답 수준
[60s]  종료
```

힌트는 **어려운 것부터 쉬운 것 순서**(T5→T1)로 열린다. 일찍 맞힐수록 실력이다.

전원 정답 시 즉시 종료. 아무도 못 맞히면 60초 만료 후 정답 공개.

### 1.2 화면

```
┌────────────────────────────────────────────┐
│  3번 방 · 그 해              5/8   R4/10   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░  24초                │
├────────────────────────────────────────────┤
│  힌트                                       │
│   1  자장면 한 그릇 2,500원                │
│   2  이 해 데뷔 — H.O.T                    │
│   3  최저임금 시급 1,485원                 │
│   ● ● ● ○ ○ ○         다음 힌트 3초        │
├────────────────────────────────────────────┤
│  ◆ 감자탕러버   1996?                     │
│  ◆ ㅋㅋ루삥뽕   아니 더 뒤일걸             │
│  ◆ 야타족       1997         ✓ 정답 +100  │
├────────────────────────────────────────────┤
│  [ 메시지 입력                        ]    │
└────────────────────────────────────────────┘
```

### 1.3 판정

| 입력 | 결과 |
|---|---|
| `1997` `1997년` `97` `97년` | 정답 |
| ±1년 (`1996`, `1998`) | **부분 점수 30** — 단 1회만. 남발 방지 |
| 그 외 4자리 숫자 | 오답. 채팅에 그대로 남음 |
| 숫자 아님 | 잡담. 판정 안 함 |

**`97` 같은 두 자리도 받는다.** 채팅으로 빨리 치려면 그게 자연스럽다.

### 1.4 정산 — 「그 해」 카드

정답 공개 후 4초. 이 게임의 콘텐츠 하이라이트다.

```
┌────────────────────────────────────────────┐
│                  1997                       │
├────────────────────────────────────────────┤
│  자장면 2,500원   지하철 400원              │
│  최저임금 1,485원  환율 1,695원 ▲          │
├────────────────────────────────────────────┤
│  · 정부, IMF에 구제금융 요청                │
│  · 영화 「접속」 개봉                        │
│  · 프로야구 우승 — 해태 타이거즈             │
└────────────────────────────────────────────┘
```

4초 동안 **채팅은 계속 열려 있다.** "아 맞다 IMF", "나 그때 초등학생" 같은 반응이 여기서 터진다. **정산 화면이 대화를 만든다.**

### 1.5 밸런싱

| 항목 | 값 |
|---|---|
| 연도 범위 | 1980~2020 (41개) |
| 같은 연도 재출제 | 방 세션 내 금지, 유저별 7일 내 회피 |
| 목표 정답률 | 라운드당 참가자의 60~80% |
| 힌트 간격 | 8초 (난이도 조절 시 6~10초) |

**필요 콘텐츠**: 연도당 힌트 30개 이상 × 41연도 = **1,200건 이상**. 라운드가 계속 도니 데일리보다 훨씬 빨리 닳는다 (04 문서).

## 2. 초성 퀴즈

### 2.1 라운드 구조

```
[0s]  초성 + 카테고리 공개
[8s]  힌트 1 공개 (설명 한 줄)
[14s] 힌트 2 공개 (모음 일부)
[20s] 종료
```

20초로 짧다. 라운드가 빨리 돌아서 리듬이 좋다.

### 2.2 화면

```
┌────────────────────────────────────────────┐
│  1번 방 · 초성 퀴즈          7/8   R7/15   │
│  ▓▓▓▓▓▓▓▓░░░░░░░░░░  11초                 │
├────────────────────────────────────────────┤
│                                            │
│          ㅅ  ㅍ  ㄱ                        │
│                                            │
│      카테고리 · 90년대 물건                 │
│      힌트 · 허리에 차고 다녔다              │
│                                            │
├────────────────────────────────────────────┤
│  ◆ ㅋㅋ루삥뽕   수펄구                     │
│  ◆ 감자탕러버   삐삐?                      │
│  ◇ 96학번       삐삐         ✓ 정답 +100  │
└────────────────────────────────────────────┘
```

초성은 **크게, 자간 넓게** 보여준다. 이게 화면의 주인공이다.

### 2.3 판정

- 정규화 후 정확히 일치 (공백·받침 오타 무관용)
- **복수 정답 허용**: `ㅅㅍㄱ` → `삐삐`가 아니라도 사전에 등록된 다른 답이 있으면 인정
- 서로 다른 답으로 여러 명이 맞힐 수 있다 → 각자 점수

### 2.4 소재

**여기가 정체성이다.** 일반 단어가 아니라 90년대 소재로 낸다.

| 카테고리 | 예 |
|---|---|
| 90년대 물건 | 삐삐 · 워크맨 · 다마고치 · 필통 · 브로마이드 |
| 그때 그 과자 | 죠스바 · 쌍쌍바 · 뽀빠이 · 자야 |
| 유행어 | 야타족 · 오빠믿지 · 쌩얼 |
| 방송 | 모래시계 · 순풍산부인과 · 이소라의프로포즈 |
| 게임 | 스타크래프트 · 바람의나라 · 크레이지아케이드 |
| 장소 | 오락실 · 만화방 · 비디오가게 · 롤라장 |

**필요 콘텐츠**: 단어 1,500개 + 카테고리·힌트. 04 문서.

### 2.5 난이도

초성만 주면 너무 어렵다. **카테고리를 처음부터 같이 준다.**

| 시점 | 정보 |
|---|---|
| 0초 | 초성 + 카테고리 |
| 8초 | 설명 한 줄 |
| 14초 | 첫 글자 모음 공개 (`ㅅ` → `삐`의 `ㅣ`) |

## 3. 단어 연상 ★

> 캐치마인드의 텍스트 버전. **그리기 도구를 만들지 않아도 되고, 콘텐츠를 사람이 만든다.**

### 3.1 라운드 구조

```
[준비]  출제자 지정 (로테이션) → 그 사람에게만 단어 3개 제시
[0s]    출제자가 하나 선택 → 라운드 시작
        나머지에게는 카테고리만 보임
[0~90s] 출제자가 채팅으로 설명
        나머지가 채팅으로 정답 시도
[종료]  정답자 나오거나 90초 만료
```

### 3.2 화면 — 출제자

```
┌────────────────────────────────────────────┐
│  7번 방 · 단어 연상           4/8   R3/10  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░  62초                │
├────────────────────────────────────────────┤
│  당신이 출제자입니다                        │
│                                            │
│        삐  삐                              │
│        카테고리 · 90년대 물건               │
│                                            │
│  ⚠ '삐', '삐삐', '무선호출기' 는 쓸 수 없어요│
├────────────────────────────────────────────┤
│  ◆ 나(출제자)  허리에 차고 다니던 거       │
│  ◆ 감자탕러버  핸드폰?                    │
│  ◆ 나(출제자)  아니 그 전에 쓰던           │
│  ◆ ㅋㅋ루삥뽕  삐삐!        ✓ 정답        │
└────────────────────────────────────────────┘
```

### 3.3 화면 — 맞히는 사람

```
│  ◆ 야타족이 출제 중                        │
│                                            │
│        ?  ?                                │
│        카테고리 · 90년대 물건               │
│        두 글자                              │
```

**글자 수만 알려준다.** 카테고리 + 글자 수면 추론이 가능해진다.

### 3.4 금칙어 자동 차단 — 이 게임의 핵심 장치

출제자가 정답을 그대로 말하면 게임이 성립하지 않는다. **서버가 자동으로 막는다.**

```
차단 대상 (자동 생성)
  · 정답 단어 그 자체            "삐삐"
  · 부분 문자열                  "삐"
  · 등록된 동의어 · 별칭         "무선호출기", "페이저"
  · 자모 분해 후 유사            "ㅃㅃ", "삣삐"
  · 영문 표기                    "beeper", "bbibbi"
  · 띄어쓰기 · 반복 변형         "삐 삐", "삐삐삐"

차단 시
  → 메시지가 전송되지 않음
  → 출제자에게만 "그 단어는 쓸 수 없어요" 토스트
  → 3회 초과 시 경고, 5회 시 라운드 스킵 (점수 0)
```

**차단 목록을 화면에 보여준다.** 뭐가 금지인지 모르면 출제자가 답답하다.

### 3.5 점수

출제자도 점수를 받아야 열심히 설명한다.

```
맞힌 사람     1등 100  2등 70  3등 50  이후 30
출제자        맞힌 사람 수 × 40  (최대 160)
              아무도 못 맞히면 0
```

**아무도 못 맞히면 출제자가 0점**인 게 중요하다. 너무 어렵게 내면 본인이 손해라서 자연스럽게 난이도가 조절된다.

### 3.6 출제자 로테이션

```
라운드 1 → A
라운드 2 → B
라운드 3 → C
...
한 바퀴 돌면 다시 A
```

중간에 나간 사람은 건너뛴다. 새로 들어온 사람은 큐 맨 뒤로.

**모든 사람이 반드시 한 번은 출제자가 된다.** 이게 참여감을 만든다.

### 3.7 왜 이게 제일 유망한가

| 이유 | |
|---|---|
| **콘텐츠 비용이 거의 0** | 단어 목록만 있으면 된다. 설명은 사람이 만든다 |
| **매번 다르다** | 같은 단어여도 설명하는 사람이 다르면 완전히 다른 라운드 |
| **웃긴 게 콘텐츠** | 이상한 설명이 나오면 그게 그날의 하이라이트 |
| **구현이 가볍다** | 그리기 도구 · 캔버스 동기화가 없다 |
| **참여감** | 모두가 출제자가 된다 |

### 3.8 위험 요소

| 위험 | 대응 |
|---|---|
| 출제자가 성의 없이 함 | 출제자 점수를 맞힌 사람 수에 연동 (§3.5) |
| 출제자가 자리를 비움 | 20초간 발언 없으면 자동 스킵, 다음 사람 |
| 금칙어 우회 | 자모 분해 · 영문 · 변형까지 차단 (§3.4). 완벽하진 않다 |
| 최소 3명 필요 | 콜드스타트에 가장 취약. 03 문서 |
| 부적절한 설명 | 채팅 필터 그대로 적용 + 신고 |

**금칙어 우회는 완전히 막을 수 없다.** 우회하면 라운드가 재미없어지고, 그건 본인 점수 손해라서 자정 작용이 어느 정도 있다. 반복 우회자는 신고 대상.

### 3.9 소재

초성 퀴즈와 단어 풀을 **공유한다.** 같은 DB에서 뽑는다.
단, 단어 연상은 **설명 가능해야** 하므로 필터가 하나 더 붙는다.

```
적합    삐삐 · 오락실 · 다마고치 · 롤라장 · 브로마이드
부적합  고유명사 중 설명이 곧 정답인 것 (예: 특정 인물 이름)
        너무 추상적인 것
```

## 4. 세 게임의 역할 분담

| | 그 해 | 초성 퀴즈 | 단어 연상 |
|---|---|---|---|
| 라운드 길이 | 60초 (느긋) | 20초 (빠름) | 90초 (긴 호흡) |
| 채팅 양 | 중 | **많음** (마구 외침) | **많음** (설명+추측) |
| 콘텐츠 소비 | 빠름 ● | 빠름 ● | **거의 없음** |
| 최소 인원 | 2 | 2 | **3** |
| 진입 장벽 | 중 (연도 감각) | 낮음 | 낮음 |
| 구현 난이도 | 중 | 낮음 | 중 (금칙어) |

**한 방에서 세 게임을 번갈아 하는 게 이상적이다.** 리듬이 달라서 물리지 않는다.
방장이 게임을 바꿀 수 있게 하고, 결과 화면에서 `다음 판은 단어 연상 어때요?` 를 제안한다.

## 4.5 게임별 싱글 · 팀전 규칙

세 게임 모두 **싱글 · 개인 멀티 · 팀전**을 지원한다 (01 문서 §1.5). 로직과 콘텐츠는 공유하고 껍데기만 다르다.

### 싱글 버전

| 게임 | 데일리 | 연습 |
|---|---|---|
| **그 해** | 힌트 순차 공개, **6번 시도**. 적게 쓸수록 고득점 | 무한 랜덤 연도 |
| **초성 퀴즈** | **60초 타임어택**, 20문제. 정답 수 × 속도 | 무한, 난이도 선택 |
| **단어 연상** | **AI 출제자와 1:1**, 5단어 연속 | 무한, AI 출제 |

**단어 연상 싱글이 AI 출제자로 성립하는 게 중요하다.** 사전 생성된 3단계 설명 스크립트를 시간에 따라 흘린다 (04 문서 §5.5.3). 사람만큼 재밌진 않지만, **혼자서도 이 게임을 맛볼 수 있게** 해서 멀티 유입의 다리가 된다.

싱글은 03 문서의 콜드스타트 완충 장치이기도 하다 — 사람이 없는 시간에 온 유저를 그냥 보내지 않는다.

### 팀전 규칙

| 게임 | 방식 |
|---|---|
| 초성 퀴즈 | 팀 채팅으로 상의 → 먼저 맞힌 팀 고득점 |
| 그 해 | 같음. 힌트가 열릴 때마다 팀 채팅이 시끄러워진다 |
| **단어 연상** ★ | **팀마다 자기 출제자.** 양 팀이 동시에 다른 단어로 진행, 먼저 맞힌 팀 승 |

팀 채팅 분리가 팀전의 핵심 설계다 — 상세는 01 문서 §6.5.

## 5. 개발 순서

| 순서 | 게임 | 이유 |
|---|---|---|
| 1 | **초성 퀴즈** | 구현이 가장 단순. 방 껍데기를 검증하는 데 최적 |
| 2 | **단어 연상** | 콘텐츠 부담이 없어 빨리 붙는다. 재미 검증의 핵심 |
| 3 | **그 해** | 콘텐츠 구축에 시간이 걸린다. 병렬로 준비 |

**그 해가 간판이지만 먼저 만들지 않는다.** 힌트 DB가 쌓이는 동안 다른 두 게임으로 방 구조를 검증한다.
